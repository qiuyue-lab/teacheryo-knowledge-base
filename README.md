## AI 角色如何使用

1. 先读 [llms.txt](llms.txt)，了解知识库全貌和导航
2. 根据需求读取对应的 `docs/` 文档
3. 需要原文细节时，到 `sources/` 按来源查找

## 更新方式

- **增量更新**：新文章发给 QClaw，按 [解析模板](templates/article-analysis.md) 处理后 push
- **知识汇总**：定期更新 `docs/` 下的知识文档，保持与素材同步
- **导航同步**：新增文档时同步更新 `llms.txt`
