# 播客访谈问题清单：切片级Agent

## 核心问题（6个）

**1. 你在做什么？**
能不能用最简单的话说说，你做的这套"切片级agent"是什么？我理解你有两层设计：第一层是帮老师快速出讲义的agent，第二层是给学生用的学习agent。这两层是怎么配合的？和让学生直接问ChatGPT有什么不同？

**2. 为什么要这么设计？**
从用大模型到做切片级agent，你是怎么想到要这么做的？为什么要把教学拆成一个个"切片"，比如作文拆成审题、立意、结构、素材...这个拆法背后的逻辑是什么？

**3. 用起来效果怎么样？**
你观察到成熟老师掌握这套工具特别快。那学生那边呢？学生用了这些AI学习，效果如何？会不会出现AI依赖症？你现在花最多时间在做什么——是设计AI，还是和学生互动？

**4. 这意味着什么？（最犀利的问题）**
如果成熟老师用你的工具把题库、讲义都搭建完了，是不是大多数老师就没有出讲义的必要了？往更远想：如果顶尖老师把自己的教学方法都做成了切片级AI并开放出来，学生只要选几个最好的AI就能学习——那其他老师是不是就没有存在的必要了？会不会"赢家通吃"，绝大多数老师被"优化"掉？

**5. 未来会怎样？**
假设题库搭建完了，成熟老师的经验都沉淀成AI了。那接下来呢？大多数老师还要做什么？5年后，你觉得你的课堂会变成什么样子？

**6. 你对教育的思考**
做这件事的过程中，有没有让你重新思考"教育到底是什么"？如果现在有老师也想尝试，你会给什么建议？
