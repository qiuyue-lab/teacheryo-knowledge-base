# 我给自己捏了个AI分身，专门帮我写公众号

去年12月，我给自己捏了一个AI分身，专门辅助我写公众号。我一般会先跟它讨论思路，让它写个初稿，然后我再调整。用了几个月，效果还不错。

但最近发现一个问题：它跟不上我的想法了。

这个分身的"认知"停留在去年12月，这几个月我写了不少新文章，有些新的思考和表达方式，它没学到。所以写出来的东西越来越不像"我会这么写的"。

我想让它"成长"一下，跟上我最近的节奏。

## 基础配置

我用的技术栈是：**Cursor（IDE工具）+ Rolex MCP（也可以用promptx）+ Claude 4.5**。这套组合能让AI不只是"回答问题"，而是真正"记住经验""建立认知""持续成长"。

下面说说我怎么做的。

## 一、让它扫描我的文章

第一步，我把最近写的30多篇文章扔给它，让它自己去读。但不是无脑读，我教它用"三层价值识别法"：

**第一层：直接可用的素材**——具体案例、真实对话、数据，可以直接引用的。**第二层：认知洞察**——我的思考方式、新视角、对问题的理解。**第三层：方法论**——可复制的方法、操作步骤、思考框架。

举个例子。我之前写过《当我开始使用Gemini进行备课》，它提取出来的不是"Gemini能生成课件"这种表面信息，而是：备课重心从"70%执行+30%思考"变成"70%决策+30%让AI执行"；三轮对话的规律是建立共同语言→暴露真实问题→规模化复制；还有具体数据比如效率提升60%。

这样它不只是"记住了一篇文章"，而是理解了我在那篇文章里的深层逻辑。

## 二、让它写"经验笔记"

读完文章后，我让它用一个工具叫`synthesize`（综合），把每次扫描中的认知记录下来。用的是这个结构：Given（遇到了什么场景）、When（做了什么思考）、Then（学到了什么）。

比如它写了一篇是这样的：

```
认知冲击：AI不是工具，是角色/伙伴

Given: 我读了《AI教研员》和《切片式Agent》
When: 我发现作者反复强调"AI不是工具"
Then: 我理解了：
  - 工具关系：领导→工具→监控用户（控制）
  - 角色关系：用户→AI→协助用户（赋能）
  - 同样的功能，关系不同，用户体验天差地别
```

这样的"经验笔记"，它写了4篇，每一篇记录一次认知跃迁。

## 三、反思：从经验到认知框架

4篇经验笔记，18个认知点，太碎了。我问它："这些认知背后，有没有更底层的原则？"

它用另一个工具叫`reflect`（反思），把4篇经验笔记"吸收"掉，提炼出7个核心原则。比如：

- AI的本质是协作关系的重构，不是功能的叠加
- 专业价值的重心从执行层转移到决策层
- 门槛降低释放的是创造力，不只是效率
- 务实理想主义是"在约束中找空间"
- 跨界影响力来自"一个内容两层价值"

这7个原则，不是我告诉它的，是它自己从30多篇文章中反思提炼出来的。它还总结了一个"元原则"：所有认知的共同点是关注"关系"而非"功能"、关注"转变"而非"技能"、关注"创造"而非"效率"。

我看到这个时挺震撼的，因为这确实是我写作的底层逻辑，但我自己从来没这么清晰地总结过。

## 四、应用：有认知框架后的变化

有了这7个核心认知，它写东西就不一样了。

它会在写作前问自己：这篇内容是否让读者感觉"我在掌控AI"？我是否强调了"决策层"的价值？我传递的是"创造的快乐"还是"技能的焦虑"？语言是否真诚？

写完后，它还会检验：读者读完能立即做什么？非核心读者读完有什么启发？我写的是"方法"还是"思维方式的改变"？

举个例子。最近它写了一篇关于AI备课的内容，草稿出来后自检："我写的是工具操作（执行层），还是教学理念的转变（决策层）？"发现太偏工具操作，于是调整，增加了"教师角色从讲授者到设计者"的深层逻辑。

这种自检能力，是它以前没有的。

## 核心逻辑

整个过程其实就是：

1. **扫描文章**，用"三层价值识别"提取信息
2. **synthesize**，把信息转化成结构化的经验
3. **reflect**，从多个经验中提炼出认知框架
4. **应用**，用认知框架指导后续的创作

这套流程让AI分身从"执行工具"变成了"成长型伙伴"。它不再是"你说什么我做什么"，而是有了自己的判断标准和思考框架。
