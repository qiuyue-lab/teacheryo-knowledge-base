### 讲故事
"上周去教博会，看到陕西师大实验小学的'AI教研员'产品。
回来发现小红书上真有老师在用，评论区好多人问怎么申请。

**AI评课系统，真的能帮我们更好地做教研吗？**

## Part 1：工具 vs 角色 - 差在哪里？

### 1.1 两个场景对比

**场景一：AI评课工具**
- 领导通知必须上传
- 收到报告：导入超标、提问次数不足、举手率待提升
- 老师第一反应：会不会被扣绩效？

**场景二：AI教研员**
- 老师主动问：我今天导入是不是太长了？
- AI回复：讲得充分，不过名师一般控制在1分钟。要看看于漪老师怎么处理的吗？
- 老师感觉：有个帮手在给建议

### 1.2 权力结构完全反了

```
评课工具：领导 → 工具 → 监控老师（老师是被评估对象）
AI教研员：老师 → 教研员 → 协助老师（老师是主动请教主体）
```

**三个核心差异：**
1. 心理安全感：被监控 vs 主动求助
2. 沟通方式：判断（这里不达标）vs 建议（可以试试这样）
3. 主体性：必须接受 vs 可以选择

### 1.3 核心洞察

不是功能的问题，是关系的问题。
老师需要的不是评价，是支持。

**关键问题：**
我们的AI评课系统，是想监控老师，还是支持老师？
如果是支持，老师到底需要什么样的支持？

## Part 2：老师真正需要什么支持？

### 2.1 备课时：AI作为生产力工具

**常见误区：**
- 让AI生成教案、做PPT、出题
- 只是省时间，教学质量没变

**真正需求：**
不是"给我一份教案"
而是"帮我想清楚这个难点怎么突破"

**案例：用Gemini备课《背影》**
```
多轮对话：
我：难点是什么？
AI：分析学生认知障碍

我：怎么突破？
AI：调用名师案例 + 提供多种方法

我：学生能理解吗？
AI：预判反应 + 应对策略
```

**判断标准：生产力工具 vs 省时间工具**
1. 解决核心问题：AI帮我解决了什么教学难题？
2. 能力提升：让我做到以前做不到的事
3. 不可替代性：去掉AI，这个效果达不到

**关键反问：去掉AI，你哪些环节做不到？**

### 2.2 课后：AI作为协作伙伴

**现在的问题：**
指出问题 → 但不知道怎么改

**真正需求：**
不是"告诉我哪里不达标"
而是"帮我看看还能怎么改进"

**理想场景：**
- AI指出差异：和名师的做法有什么不同
- 提供改进路径：可以怎么调整
- 给出具体方案：根据你的班级情况

### 2.3 持续成长：名师经验随时可得

**以前的困境：**
- 听名师课机会少
- 资源分散难找
- 问教研员没时间

**AI+名师课堂数据库：**
- 随时问：名师都怎么讲的？
- 立刻调：调出优秀老师做法
- 能对比：理解设计思路
- 可借鉴：根据自己情况调整

**完整闭环：**
备课 → 上课 → 评课 → 改进 → 下次备课

### 2.4 对教研员的启示

**评课标准的转变：**
从评"用了什么"到评"解决了什么"
- AI帮老师解决了什么核心教学问题？
- 老师的教学能力因为AI提升了什么？
- 去掉AI，哪些效果达不到？

## Part 3：教研员的角色重构

### 3.1 传统教研的局限

```
听课 → 评课 → 给建议
基于：经验 + 标准
```

问题：
- 经验有上限
- 精力有限，只能指导少数人
- 经验难以规模化传播

**AI时代的矛盾：**
老师需求变了，教研员还在用老方法

### 3.2 教研员的三个新角色

**角色1：体系构建者**
- 把教研经验变成可复用的框架
- 把名师案例变成可调用的知识库
- 把评价标准变成可执行的规则

**角色2：资源组织者**
- 核心资产：名师课堂数据库
- 按知识点分类的视频片段
- 可检索的教学设计案例
- 可调用的教学方法库

**角色3：生态设计者**
- 设计完整闭环：备课→上课→评课→改进→沉淀
- 让AI、老师、数据形成生态
- 让优秀成果规模化复制

### 3.3 精准教研的新定义

**精准在哪里？**
1. 需求精准：理解老师在不同阶段的真实需求
2. 支持精准：在合适时机提供合适支持（个性化）
3. 资源精准：让名师经验精准匹配到需要的老师
4. 规模精准：让精准支持可以规模化

## Part 4：如何落地

### 第一步：转变评课方式
- 从监控式评课到支持式教研
- 让老师主动使用，而非被动上传
- 建立"问题→建议→改进"闭环

### 第二步：构建完整闭环
- 备课教研：看老师如何用AI设计认知路径
- 听课教研：看AI在哪些环节真正起作用
- 评课教研：基于AI分析+名师对比给改进路径

### 第三步：体系化沉淀
- 收集整理本区优质课（按知识点分类）
- 梳理优秀教师经验（形成可复用框架）
- 培训老师使用方法（如何让AI成为生产力工具）

### 能做出什么成果？
- 区域：建立AI时代教研体系，形成示范
- 学校：教师会用AI提升教学，新教师快速成长
- 教师：备课质量提升，随时得到支持
- 教研员：从经验型到体系型跃迁，价值放大
