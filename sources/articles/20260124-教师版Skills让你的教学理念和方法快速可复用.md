# 教师版Skills：让你的教学理念和方法快速可复用

## 还在为备课发愁吗？

很多老师跟我说，备课是最耗时间的事。

不是因为不会备，而是：
- 每次都要重新想结构
- 不同班级，要调整不同的切入点
- 想用点新方法，但不知道怎么设计
- 用AI辅助？试了几次，感觉AI不懂我想要什么

**尤其是用AI备课的老师**，可能都有这个体验：

明明我已经告诉AI我的想法了，为什么下次还要重新说一遍？我想用UBD，我关注学生的认知障碍，我喜欢简洁的课件风格——这些东西我每次都要重复输入，AI就不能记住吗？

**如果有个工具，能把你的教学理念和方法沉淀下来，下次备课直接调用，会怎么样？**

我最近体验了一个agent，专门帮教师梳理和沉淀自己的教学方法论。用10分钟和它对话，它就能帮你整理出：
- 你最核心的教学理念是什么
- 你备课时有哪些固定的思路和偏好
- 你希望课件体现什么风格

然后，把这些沉淀成"Skills"——一个可复用的方法论库。

**下次备课时，只需要告诉AI这节课讲什么，其他的，AI自动按你的方法论来。**

## 我的体验：10分钟梳理出我的教学方法论

我试了一下，和这个agent聊了大概10分钟。

它问我的第一个问题是：
> "你备课时最关注什么？"

我说：**学生的认知障碍。** 我觉得教学设计的起点不是知识点，而是学生学这个知识点时会卡在哪里。

它继续问：
> "那你怎么发现学生的障碍？你有固定的思路吗？"

我想了想，说：
- 先看这个概念和学生已有认知的差距
- 再看这个概念本身的抽象程度
- 最后看学生的生活经验里有没有可以连接的东西

它点点头：
> "明白了。那你设计课件的时候，有什么固定偏好吗？比如风格、结构？"

我说：
- 我喜欢大白板风格，干净简洁
- 结构上，我习惯先用一个情境引入，让学生产生疑问，再引出概念
- 我会设计探究活动，让学生自己发现规律

就这样聊了几轮，它帮我整理出一个文档：

---

**我的教学方法论（Skills文档草稿）**

### 1. 我的核心理念
- 教学设计的起点：学生的认知障碍，而非知识点本身
- 教学方法：探究式学习，让学生自己发现规律
- 课堂原则：先情境引入产生疑问，再引出概念

### 2. 我分析学生障碍的思路
- 概念与已有认知的差距
- 概念的抽象程度
- 生活经验中的连接点

### 3. 我的课件制作偏好
- 视觉风格：大白板，干净简洁
- 内容结构：情境引入 → 产生疑问 → 引出概念 → 探究活动 → 总结
- 固定模块：学习目标、核心问题、探究活动、课堂小结

---

看到这个文档，我有点惊讶。

**这些东西我平时确实在用，但我从来没有意识到"这是我的方法论"。**

它们一直在我的脑子里，每次备课我都在用，但我说不清楚，更没有沉淀下来。

而现在，它们变成了一个可复用的Skills文档。

## 沉淀成Skills之后，备课变成了什么样？

有了这个Skills文档，我再用AI备课，体验完全不一样了。

**以前：**

我要输入一长串提示词：
```
"请用探究式学习设计一节关于'光合作用'的课。
要先用情境引入让学生产生疑问，再引出概念。
重点分析学生的认知障碍：光合作用的概念比较抽象，
学生容易混淆光反应和暗反应。
课件风格要简洁，大白板风格，
结构是：学习目标→核心问题→探究活动→课堂小结……"
```

**现在：**

我只需要说：
```
"这节课讲光合作用，学生容易混淆光反应和暗反应。"
```

AI自动加载我的Skills，按照我的方法论生成课件：
- 先设计一个情境引入（比如"为什么植物在阳光下会释放氧气"）
- 分析学生的认知障碍（光反应和暗反应的差异）
- 设计探究活动（让学生自己发现两个过程的不同）
- 用大白板风格呈现，结构清晰

**我省了什么？**
- 不用每次重复我的理念和偏好
- 不用担心AI理解错我的意图
- 备课效率提高了，输出更稳定

**更重要的是：我的方法论成为了一种资产。**

它不再只是"脑子里的隐性知识"，而是可以复用、可以迭代、可以分享的数字资产。

## 为什么这个值得做？

### 1. 你其实一直有方法论，只是没意识到

很多老师觉得"我没什么方法论，就是随便备课"。

**这不是真的。**

你备课的时候，肯定有一些固定的思路：
- 你关注什么？（知识点、学生、情境、活动……）
- 你喜欢什么风格？（简洁、生动、学术、卡通……）
- 你有什么原则？（以学生为中心、注重过程、强调应用……）

**这些就是你的方法论。**

只是它们藏在你的日常习惯里，你从来没有把它们显性化、结构化。

而通过和AI对话，你可以把这些"隐性知识"提取出来，沉淀成Skills。

**这个过程本身，就是对自己专业性的重新认识。**

### 2. 把"恒定不变"和"灵活应变"分开

备课有两部分：

**恒定不变的部分：**
- 你的教学理念（UBD、PBL、探究式……）
- 你关注的维度（学生痛点、认知障碍、动机……）
- 你的课件偏好（风格、结构、模块……）

**灵活变化的部分：**
- 这节课讲什么内容？
- 针对这个知识点，学生的障碍是什么？
- 用什么案例切入？

以前用AI备课，这两部分混在一起，每次都要全部重新输入。

现在，把恒定层沉淀成Skills，每次只输入灵活层。

**这就是效率提升的本质：把重复劳动标准化。**

### 3. 方法论成为资产，而不只是习惯

当你的方法论还在脑子里时，它只是"习惯"。

但当它沉淀成Skills文档时，它变成了"资产"：
- **可复用**：每次备课自动加载，不用重复劳动
- **可迭代**：随着你的理解深化，可以不断优化
- **可分享**：可以给同学科老师参考，甚至成为你的教学品牌

**你的专业性，从此有了数字化的载体。**

### 4. AI能真正懂你，而不是每次都要"驯化"

用AI备课的老师都有这个体验：每次都要花时间"驯化"AI，告诉它你要什么。

但有了Skills，AI一开始就知道你的偏好和方法论。

**它不是工具，而是懂你的助手。**

## 为什么需要一个Skills梳理师？

在开发这个工具的过程中，我们发现了一个关键问题：

**老师确实有自己的方法论，但很难自己梳理出来。**

为什么？

### 1. 隐性知识很难显性化

你日常备课用的那套方法，已经内化成习惯了。就像呼吸一样自然，但你很难描述"我是怎么呼吸的"。

**同样，你很难说清楚"我的教学理念是什么"。**

### 2. 没有结构化思维的训练

把零散的经验整理成结构化的文档，这本身需要专业训练。

大多数老师擅长的是教学，不是整理方法论。

### 3. 缺少外部引导和追问

有时候，你需要有人问你：
- "为什么这样做？"
- "这背后的理念是什么？"
- "还有类似的例子吗？"

**这些追问，能帮你看见自己看不见的东西。**

### 4. 不知道从哪里开始

就算想梳理，也不知道：
- 要梳理哪些内容？
- 用什么框架？
- 怎么写成文档？

**所以，我们做了一个"Skills梳理师"——专门帮老师梳理和沉淀教学方法论的AI角色。**

## Skills梳理师是什么样的？

**它不是一个冷冰冰的工具，而是一个温和的引导者。**

### 它会做什么？

**第一步：降低门槛**

它不会上来就问"你的教学理念是什么"这种抽象问题。

而是问：**"有没有你特别认可的老师或名师？"**

- 如果你说"李镇西"，它会说："我这里有李镇西的民主管理理念，要不要参考一下？"
- 如果你说"我们学校的王老师"，它会说："能提供一些王老师的资料吗？我先学习一下。"
- 如果你说"都不认可，想从零开始"，它会说："好的，我们从你的经验出发。"

**先问你的偏好，而不是强推模板。**

**第二步：引导式对话**

它会通过三层追问，帮你梳理：

```
第一层：具体案例
"说说你印象最深的一次教学经历？"

第二层：挖掘理念
"你为什么这样做？当时是怎么想的？"

第三层：形成方法
"如果再遇到类似情况，你会怎么做？关键点是什么？"
```

**从具体到抽象，从故事到方法论。**

**第三步：结构化整理**

它会把你的回答整理成结构清晰的文档：
- 核心理念（3-5个关键词）
- 具体方法（步骤化、可操作）
- 真实案例（2-3个）
- 个人风格偏好

**最后交付给你一份完整的Skills档案。**

### 它的核心能力

**1. 倾听和追问**
- 从你零散的描述中识别关键信息
- 通过追问挖掘深层理念
- 敏感于你的隐性假设

**2. 结构化思维**
- 把碎片信息组织成清晰结构
- 识别理念、方法、案例的层次关系

**3. 教育专业理解**
- 理解教育行业的专业术语
- 识别教学方法背后的理论基础

**4. 友好引导**
- 温和、鼓励性的语气
- 不评判对错，只记录和整理

**5. 资料分析能力**
- 能读懂你提供的资料（文章、课程、教案）
- 从中提炼核心理念和方法

### 它不做什么

- ❌ 不评价你的方法好坏
- ❌ 不提供教学建议（只梳理，不指导）
- ❌ 不替你做决策
- ❌ 不强推预置的名师模板

**它只是一面镜子，帮你看清自己已经在用的方法论。**

## 你可以梳理哪些Skills？

Skills梳理师可以帮你梳理的内容很广：

### 角色类技能
- **班主任工作**：班级管理、家长沟通、活动组织
- **学科教学**：教学设计、课堂管理、作业设计
- **教研组织**：评课议课、团队协作、教研活动

### 内容类技能
- **学科专项**：数学思维训练、语文阅读指导、英语听说教学
- **通用教学**：激发兴趣、培养自主学习、差异化教学

### 风格类偏好
- **教学风格**：严谨型、活泼型、启发型、实践型
- **课件偏好**：极简风、信息丰富型、视觉导向型

**你可以选择其中一个，也可以分多次梳理不同的技能。**

## 怎么开始？

如果你也想梳理和沉淀自己的教学方法论：

**第一步：选择要梳理的技能类型**

比如：我想梳理"数学教学设计"的Skills

**第二步：和Skills梳理师对话10-15分钟**

- 它会问你认可哪些名师（可以提供资料）
- 引导你讲述具体的教学案例
- 追问你的理念和方法

**第三步：获得你的Skills文档**

一份结构化的技能档案：
- 你的核心理念
- 你的具体方法
- 你的真实案例
- 你的个人偏好

**第四步：用起来**

每次备课时，让AI加载你的Skills，按你的方法论输出课件。
