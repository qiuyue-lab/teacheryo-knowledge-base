## 三、周节奏模板

每周7天，公众号和小红书各日更一篇。部分内容跨平台适配复用。

| 星期 | 公众号 | 小红书 | 说明 |
|------|--------|--------|------|
| **周一** | 🔴 重磅深度文 | 🟢 深度文的精华金句版 | 重磅文章当天发公众号，同步出一张小红书金句卡 |
| **周二** | 🟡 中等拆解文 | 🟡 同话题小红书适配版 | 同一个话题，公众号1200字，小红书800字精简版 |
| **周三** | 🟢 轻量内容 | 🟢 独立轻量内容 | 两个平台各发不同的轻量内容 |
| **周四** | 🟡 中等拆解文 | 🟡 同话题小红书适配版 | 同周二 |
| **周五** | 🟢 轻量内容 | 🟢 独立轻量内容 | 同周三 |
| **周六** | 🟡 中等拆解文 | 🟡 同话题小红书适配版 | 同周二 |
| **周日** | 🟢 轻量内容 | 🟢 互动话题 | 周日轻松一点，互动为主 |

**每周工作量统计：**
- 公众号：1篇重磅 + 3篇中等 + 3篇轻量 = 7篇
- 小红书：3篇中等适配 + 3篇轻量 + 1篇金句卡 = 7篇
- 实际新写内容：1篇重磅 + 3篇中等 + 6篇轻量 = 10篇（小红书中等是公众号的精简版，不算新写）
- 其中轻量内容每篇10-20分钟即可完成

## 六、执行建议

1. **每周日晚上**：确认下周7天的选题，从这个清单里选。
2. **中等内容的写法**：不是复制原文的一段，而是把一个点重新写——新开头、新角度、可以加新的案例或读者反馈。
3. **轻量内容的写法**：不要想太多，看到什么有感触的直接写，300-600字，截图配文字就行。
4. **小红书适配**：公众号中等文章发完后，马上精简成800字小红书版——删掉解释性段落，保留核心观点和金句，结尾加评论引导和标签。
5. **弹性机制**：如果当天有新灵感或热点话题，可以替换原定选题。日历是参考，不是死规矩。
