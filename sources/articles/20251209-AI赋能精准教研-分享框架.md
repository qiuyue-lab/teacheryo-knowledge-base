# AI赋能精准教研 - 分享框架

**分享对象**：北京某区教研员
**核心目标**：
1. 建立AI时代教学、学习、评价变化的深层认知
2. 重新定义AI时代教研的价值和方法
3. 提供可落地的实践路径

**总时长**：约40分钟

---

## 核心逻辑链

```
教：AI作为教师的生产力工具（不是省时间的工具）
学：AI作为学生的生产力工具（协作但不依赖）
评：评价AI融合质量 + 教师引导质量
    ↓
当教、学、评都变了 → 教研的内容和方式必然要变
    ↓
教研员的新角色：体系构建者、数据解读者、生态设计者
```

## 开场：一个根本问题

### 提出矛盾

"大家都在做AI+教学，很多学校也在开AI公开课。

- 学生的学法变了吗？
- 我们的评价变了吗？

今天想和大家讨论：
当教、学、评都在发生本质变化时，
**AI时代的教研，到底应该研究什么？**"

## Part 1：教的变化 - AI作为教师的生产力工具

### 1.1 一个常见的困惑

**现象：**
很多老师说"我在用AI"
- 用AI生成了教案
- 用AI做了PPT
- 课件里插了AI生成的图片

**但问题是：**
这真的改变了什么吗？
- 备课质量提升了吗？
- 教学难点突破了吗？
- 学生理解更深了吗？

**往往没有。**

**为什么？**
因为只是把AI当"工具"用了，没有当"生产力工具"用

### 1.2 什么叫AI作为教师的生产力工具

**关键区别：**

**工具使用：**
- AI帮我做了一件具体的事
- 比如：生成教案、做课件、出题
- 本质：省了时间，但教学质量没变

**生产力工具：**
- AI帮我解决了教学中最核心的问题
- 比如：
  - 找到学生真正的认知难点在哪
  - 获得我自己想不到的教学灵感
  - 设计出以前做不到的教学环节
- 本质：**让我能做到以前做不到的事，做得比以前更好**

### 1.3 具体案例：AI如何成为生产力工具

#### 案例1：用Gemini备课《背影》

**不是：**
让AI写一份教案 → 我稍微改改 → 用

**而是：**
```
我：这节课的难点是什么？
AI：分析学生认知障碍 + 提供多个角度

我：如何突破这个难点？
AI：调用名师案例 + 给出设计建议

我：这个设计学生能理解吗？
AI：预判学生可能的反应 + 提供应对策略

（多轮对话，每轮都在解决真实的教学问题）
```

**结果：**
- 不是得到一份教案
- 而是经过深度思考的教学设计
- AI让我的备课质量提升了一个层次

#### 案例2：课堂上学生用AI（真实课例）

**传统方式：**
老师讲历史事件 → 学生听 → 记笔记

**AI融合方式：**
- 老师提出核心问题
- 学生用AI搜索相关资料（不是让AI直接给答案）
- 学生基于搜索到的资料进行讨论
- 老师在关键处引导和价值判断

**关键：**
- 不是让AI代替学生思考
- 而是在合适的环节，让AI成为协作助手
- 学生通过AI获得的是**思考材料**，而非**思考结果**

### 1.4 AI作为生产力工具的三个判断标准

**判断1：解决核心问题**
- ❌ 用AI做了什么→ 这是工具使用
- ✅ AI帮我解决了什么教学难题 → 这是生产力

**判断2：能力提升**
- ❌ AI让我省时间
- ✅ AI让我做到以前做不到的事

**判断3：不可替代性**
- ❌ 去掉AI，课还是这么上
- ✅ 去掉AI，这个教学效果达不到

**反问：**
"如果去掉AI，你这节课哪些环节做不到？"
- 如果都能做到 → 只是用了工具
- 如果有做不到的 → 才是生产力工具

### 1.5 对教研员的启示

**以前评课看：**
- ❌ 用了哪些AI工具
- ❌ 课件多炫酷
- ❌ 环节是否完整

**现在评课要看：**
- ✅ AI帮老师解决了什么核心教学问题？
- ✅ 老师的教学能力因为AI提升了什么？
- ✅ 如果去掉AI，哪些教学效果达不到？

**这是教研内容的第一个根本变化：**
从评"用了什么"到评"解决了什么"

## Part 2：学的变化 - AI作为学生的生产力工具

### 2.1 另一个常见的困惑

**现象：**
很多课堂说"学生在用AI"
- 学生问AI几个问题
- 学生让AI生成一些内容
- 学生拿着AI的答案交作业

**但问题是：**
学生真的学到了什么吗？
- 只是得到了答案？
- 还是真的理解了？
- 思维能力提升了吗？

**往往是：只是换了个方式抄答案**

### 2.2 什么叫AI作为学生的生产力工具

**关键不是"用AI"，而是"在合适的环节用AI做什么"**

#### 错误的用法（工具使用）：
```
学生：AI，这道题怎么做？
AI：给出完整答案和步骤
学生：抄下来，交作业
```
→ AI代替了学生思考

#### 正确的用法（生产力工具）：

**案例：历史课学生用AI**

```
老师提问：为什么这个历史事件会发生？

学生不是问AI"答案是什么"
而是：
1. 用AI搜索事件的背景资料
2. 用AI搜索不同历史学家的观点
3. 用AI搜索相关的经济数据、地理环境
4. 拿着这些材料，和同学讨论、分析
5. 形成自己的判断
```

**AI的角色：**
- 不是给答案
- 而是提供**思考材料**
- 学生基于材料进行**独立思考和判断**

### 2.3 AI作为学生生产力工具的关键

**关键1：在合适的环节使用**

不是全程用AI，而是：
- 需要搜集资料时 → 用AI
- 需要多角度思考时 → 用AI找不同观点
- 需要验证想法时 → 用AI检验
- 需要深度思考时 → 不用AI，自己想

**关键2：获得的是材料，不是结果**

```
错误：AI，给我一篇关于XX的作文
正确：AI，关于XX话题，有哪些不同的观点？
      帮我找3个支持观点A的例子
      帮我找2个反对观点A的理由
      （然后学生自己组织、思考、写作）
```

**关键3：AI协作，不是AI代替**

学生要清楚：
- 我在哪个环节用了AI
- AI帮了我什么
- 哪些是我自己的思考和判断

### 2.4 学生能力的重新定义

**以前的好学生：**
- 知识记得牢
- 题做得快
- 考试分数高

**现在的好学生：**
- 会提出好问题
- 会搜集和筛选信息
- 会判断信息的真伪
- 会综合运用知识+工具解决真实问题
- **会和AI协作，但不依赖AI**

### 2.5 案例：作业设计的转变

**传统作业：**
"完成课后习题1-10"
→ 考验记忆和套路

**AI时代的作业：**
"用AI协助，完成一个XX问题的研究报告：
1. 说明你用AI搜集了哪些资料
2. 你是如何判断这些资料可信度的
3. 你综合这些资料得出了什么结论
4. 哪些是AI提供的，哪些是你自己的思考"

→ 考验：
- 问题分解能力
- 信息搜集和筛选能力
- 批判性思维
- 独立判断能力
- **AI协作但不依赖的能力**

### 2.6 对教研的启示

**以前教研关注：**
学生掌握了吗？

**现在教研应该关注：**
- ✅ 学生在哪个环节用了AI？用对了吗？
- ✅ 学生是获得答案还是获得思考材料？
- ✅ 学生的思考过程可见吗？
- ✅ 学生会协作但不依赖吗？
- ✅ 学生的真实能力（而非AI的能力）提升了吗？

**这是教研内容的第二个根本变化：**
从关注"学会了什么"到关注"会用AI学什么、怎么学"

## Part 3：评的变化 - 评价AI融合质量

### 3.1 核心问题

当学生可以用AI时，我们到底在评价什么？
- AI的能力？
- 还是学生的能力？

### 3.2 评价对象的转变

**以前评：知识掌握**
- 记住了吗？
- 会做题吗？
- 考试分数高吗？

**现在评：两个维度**

**维度1：学生的真实能力**
- 会提出好问题吗？
- 会判断AI给的信息吗？
- 会在合适的环节用AI吗？
- 会区分哪些是AI的、哪些是自己的思考吗？
- **会协作但不依赖吗？**

**维度2：教师的引导质量**
- 老师是否在关键环节引导了？
- 老师是否帮助学生建立了判断标准？
- 老师是否让AI成为生产力工具而非替代工具？

**关键洞察：评价学生，本质上也是在评价教师的引导**

### 3.3 案例：作业设计的对比

**传统作业：**
"完成课后习题1-10"
→ 只评价答案对错

**AI时代的作业：**
"用AI协助完成XX问题的研究：
1. 你用AI搜集了哪些资料？
2. 你如何判断这些资料的可信度？
3. 你的结论是什么？
4. 哪些是AI提供的，哪些是你的思考？"

→ 评价：
- 问题分解能力
- 信息筛选能力
- 批判性思维
- **AI协作但不依赖的能力**

### 3.4 新的评课标准

**以前评课看：**
- 教学目标达成了吗
- 学生掌握知识点了吗
- 课堂设计完整吗

**现在评课要看：**
- ✅ 学生在哪个环节用了AI？用对了吗？
- ✅ 老师在关键处的引导到位吗？
- ✅ 学生的真实能力（而非AI的能力）提升了吗？
- ✅ 去掉AI，这节课的核心价值还在吗？

**评价标准的核心转变：**
从评"讲得好不好"到评"学生真实能力是否提升"+"教师引导是否到位"

### 3.5 对教研的启示

**这是教研内容的第三个根本变化：**
从评价知识掌握，到评价AI融合质量和教师引导质量

## Part 4：回到教研 - AI时代教研的价值重构

### 4.1 当教、学、评都变了，教研在研究什么？

我们刚才讲了：
- 教的变化：AI是生产力工具（不是省时间的工具）
- 学的变化：学生要会协作但不依赖
- 评的变化：评的是真实能力和引导质量

**那现在的问题是：**
教研员怎么帮老师做到这些？

**传统教研：**
```
听课 → 评课 → 给建议
基于：经验+标准
```

**问题：**
- 教研员的经验再丰富，也有上限
- 教研员的精力再充沛，也只能深入指导少数人
- 教研的经验难以规模化传播

**AI时代的新矛盾：**
教学变了，教研员还在用老方法研究

### 4.2 AI时代教研的三个新价值

#### 价值1：体系构建者

**不是传授个人经验**

**而是：**
- 把教研经验变成可复用的框架
- 把名师案例变成可调用的知识库
- 把评价标准变成可执行的规则

**举例：AI教研员角色**
- 不是教研员本人给每个老师指导
- 而是把教研方法论固化成AI可以执行的流程
- 一个教研员+AI体系 = 服务100个老师

#### 价值2：数据解读者

**不是凭经验判断**

**而是：**
- 基于学生学习过程数据精准诊断
- 看到以前看不到的认知路径
- 发现教学设计的真实问题

**举例：教学评一体化**
- AI记录每个学生和系统的交互
- 教研员看数据：哪里卡住了？为什么？
- 精准定位问题，而非靠猜

#### 价值3：生态设计者

**不是点对点指导老师**

**而是：**
- 设计区域教研的完整生态
- 让AI、老师、学生、数据形成闭环
- 让好的教研成果能够规模化复制

### 4.3 教研员的角色转变

```
从"经验传授者" → "知识体系架构师"
从"听课评课者" → "教学生态设计者"
从"个体指导者" → "AI教研系统调教者"
```

**核心转变：**
不是AI替代教研员
而是教研员通过AI放大自己的价值

### 4.4 精准教研的新定义

**精准在哪里？**

1. **认知精准**：看到学生真实的认知过程
2. **诊断精准**：基于数据而非经验判断
3. **反馈精准**：个性化而非一刀切
4. **规模精准**：让精准指导可以规模化

**这才是AI赋能精准教研的本质**

## Part 5：如何做 - 实践路径

### 5.1 从哪里开始？

#### 三个实践方向

**1. 重构教研流程**
- 备课教研：不只看教案，看老师如何设计认知路径
- 听课教研：不只看教学，看学生认知过程和AI协作
- 评课教研：不只给建议，看数据支撑

**2. 建立数据闭环**
- 选一个学科试点
- 用工具记录完整的教学评数据
- 基于数据做精准教研

**3. 体系化沉淀**
- 把教研经验变成框架
- 把教研流程变成可复用的系统
- 让AI学习你的教研方法论

### 5.2 能做出什么成果？

**区域层面：**
- 建立一套AI时代的教研体系
- 形成可复制的区域经验
- 在其他区域形成示范效应

**学校层面：**
- 老师真正会用AI融入教学
- 有数据支撑的精准教学
- 可对外展示的AI融合课

**个人层面：**
- 教研员的专业成长
- 从经验型到体系型的跃迁
