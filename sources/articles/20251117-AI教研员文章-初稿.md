# 为什么同样的功能，叫"AI教研员"就火了？

昨天去教博会逛了一圈，看到陕西师大实验小学做的"AI教研员"。

回来刷小红书，发现真有老师在用，评价还不错，评论区好几个人问怎么申请。

这让我想起一个对比：希沃做评课工具很多年了，功能其实差不多，但我之前听到的老师反馈都不太好。

同样是评课、给反馈，为什么反应这么不同？


我想了很久，发现了一个关键：

**不是功能的问题，是关系的问题。**


## 工具 vs 角色，差一个字，差了什么？

希沃的定位：评课工具

陕西师大的定位：AI教研员


看起来只是名字不同，但老师的感受完全不一样。


**工具意味着什么？**

这是领导用来管理我的东西。

我是被观察、被评估的对象。

权力关系是这样的：领导 → 工具 → 控制老师


**教研员意味着什么？**

这是来帮我的专家。

我是主体，可以选择要不要听建议。

权力关系是这样的：老师 → 教研员 → 协助老师


同样的评课功能，但**权力结构反了**。

一个让我感觉"被监控"。

一个让我感觉"有帮手"。


这就是为什么"AI教研员"这四个字这么值钱。


## 角色化到底改变了什么？

我和校长聊了聊，他说做这个产品是因为集团校需要提升整体师资水平，评课是个抓手。

从管理角度，这个逻辑很顺。

但从老师角度，感受就不一样了。


如果你告诉我："这是个评课工具，领导要求用"

我心里想的是：
- 会不会被扣分？
- 会不会被领导盯上？
- 又多了一个监控我的东西


如果你告诉我："这是个AI教研员，可以帮你"

我心里想的是：
- 有问题可以问它
- 它会给建议，我可以选择听不听
- 多了一个帮手


**同样的功能，但心理感受完全不同。**


具体来说，有三个关键差异：


### 1. 心理安全感

工具：被监控、被评估，我是透明的

教研员：有帮手、可请教，我是安全的


### 2. 沟通方式

工具："这里有问题"（冷冰冰的判断）

教研员："这里可以试试这样做"（温暖的建议）


### 3. 主体性

工具：我必须接受它的评估

教研员：我可以选择要不要采纳


这就是"角色化"的力量。

不是技术问题，是关系设计。


## 但现在的AI教研员还不够完整

陕西师大做对了两件事：
1. 角色定位（AI教研员）
2. 名师课堂数据库

但如果只是用来评课，还没发挥出全部价值。


我跟校长聊的时候，突然想到一个场景：


**备课时**

新老师：明天要讲分数除法，不知道怎么引入

AI教研员：于漪老师用了"分蛋糕"的故事，xxx老师用了生活中分东西的场景。你想看具体怎么讲的吗？


**上完课**

AI教研员：你这节课的导入不错，但在概念讲解这里，和名师有些差异

老师：什么差异？

AI教研员：名师在这里会先让学生动手操作，你直接讲了。要不要看看他们怎么设计的？


**改进时**

老师：那我下次怎么调整？

AI教研员：我帮你设计一个操作环节...


你看，**这才是完整的AI教研员：备课+评课+改进的闭环。**

不只是课后打分，而是全流程的协作伙伴。


## 名师课堂才是核心资产

为什么名师课堂数据这么重要？

因为它解决了新教师成长最核心的问题：**我想知道优秀的老师怎么做的。**


以前：
- 听名师课 → 机会少，一学期能听几次就不错了
- 看视频 → 资源分散，找起来费劲
- 问教研员 → 不一定有时间，而且很难说清楚


现在如果有AI教研员+名师课堂：
- 随时问
- 立刻看到多个名师的做法
- 还能根据自己的情况调整


这才是AI的真正价值：**让名师经验随时可得。**

不是替代教研员，是让每个老师都能随时得到名师级的指导。


而且，名师课堂不应该只用来评课（课后对比）。

更大的价值在备课（课前学习）。


想象一下：

**现在**：上完课 → AI告诉你"这里名师会这样做"（事后诸葛亮）

**未来**：明天要上课 → AI告诉你"这里名师会这样做"（提前指导）


哪个更有价值？


## 一个更大的启发

这个案例让我想了很多。

不只是AI教研员，可能所有AI产品都需要思考一个问题：


**你想成为用户的工具，还是用户的伙伴？**


做AI产品时，我们往往会想：
- 它能做什么功能？
- 它能提高多少效率？
- 它能解决什么问题？


但可能更重要的问题是：
- 我希望和用户建立什么关系？
- 用户使用它时，觉得自己是什么角色？
- 这个产品是帮助用户，还是控制用户？


**工具思维 → 角色思维**

**效率优先 → 关系优先**

**功能设计 → 体验设计**


这可能是AI时代产品设计的新范式。


因为AI和传统软件不一样。

传统软件是工具，我用它完成任务。

AI更像协作者，我和它一起完成任务。


既然是协作者，那关系设计就变得至关重要。


## 写在最后

AI教研员这个概念刚刚起步。

陕西师大做的不错，至少让老师们开始接受这个概念。

但还有很多空间可以探索：
- 备课+评课+改进的完整闭环
- 名师课堂数据的深度利用
- 真正以老师为主体的协作关系


我自己也在想，如果让我来设计一个AI教研员，会是什么样。

可能不会从评课开始。

而是从备课开始。

让每个老师在备课时，都能随时得到名师的经验。


（有机会再展开聊）


最后问一个问题：

你用过的AI产品，有多少真的把你当成"主体"，而不是被服务的"对象"？

或者说，有多少AI产品让你感觉它是你的伙伴，而不是你的工具？


可能这个差别，就是下一代AI产品的分水岭。
