# AI赋能精准教研 - 分享框架 v2.0


## 开场：抛出核心问题

**AI评课系统，真的能帮我们更好地做教研吗？**

---

## Part 1：作为评课工具和作为AI教研员的对比

评课工具：领导 → 工具 → 监控老师（老师是被评估对象）
AI教研员：老师 → 教研员 → 协助老师（老师是主动请教主体）
```

**三个核心差异：**
1. 心理安全感：被监控 vs 主动求助
2. 沟通方式：判断（这里不达标）vs 建议（可以试试这样）
3. 主体性：必须接受 vs 可以选择

### 核心洞察

不是功能的问题，是关系的问题。
老师需要的不是评价，是支持。

**关键问题：**
我们的AI评课系统，是想监控老师，还是支持老师？
如果是支持，老师到底需要什么样的支持？


## Part 2：老师的真实困惑

### 2.1 AI融合教学，到底融合的是什么？

**ai融合教学，不是数字人/让图片动起来，而是当课堂中有了一个新的智能体，我们需要考虑“师-AI-生”的新型课堂组织关系**

**案例：ai作文课**

### 2.2 第一层理解：AI是什么？

**正确理解：AI是生产力工具**

**举例：ai最大的价值是用来帮助自己做杂活吗？**

### 2.3 第二层理解：AI应该怎么用？

**案例：用Gemini备课《背影》**

不是：让AI写教案
而是：多轮对话解决真实问题

```
我：这节课的难点是什么？
AI：分析学生认知障碍

我：怎么突破这个难点？
AI：调用名师案例 + 提供多种方法

我：学生能理解吗？
AI：预判反应 + 应对策略
```

**关键：**
- AI不是替代我思考
- 而是协助我深度思考
- 让我能做到以前做不到的教学设计

### 2.4 第三层理解：AI应该如何展示？（公开课的困境）

**现在公开课的问题：**
- 刻意展示AI的使用
- 为了用AI而用AI
- 评课标准还是看"用了什么AI工具"

**正确的展示：**
- 展示利用AI备课的过程
- 分享老师/学生和AI对话的过程
- 接受在课堂上生成的不确定性

### 2.5 老师现在需要什么样的教研支持？

**当老师有了这些困惑，需要的支持是：**

**备课时：**
- 不是给我现成的教案
- 而是教我如何用AI深度思考教学设计

**课后：**
- 不是告诉我"这里用AI不达标"
- 而是帮我看"AI用得对不对、解决问题了吗"

**持续成长：**
- 随时能看到：优秀老师怎么用AI的
- 理解：为什么这样用、解决了什么问题
- 借鉴：如何用到我的课堂

**完整闭环：**
备课（学会用）→ 上课（实践）→ 评课（反馈）→ 改进（提升）

### 2.6 对教研员的启示

**老师的困惑本质上是：**
没有正确理解AI + 不知道如何使用AI + 不知道如何展示AI

**教研员应该做的：**
- 帮助老师建立对AI的正确认知（生产力工具，不是噱头）
- 提供正确使用AI的方法和案例
- 建立新的评价标准（评解决问题，不是评用了什么）

## Part 3：教研员的角色重构

### 3.1 传统教研的局限

```
听课 → 评课 → 给建议
基于：经验 + 标准
```

问题：
- 经验有上限
- 精力有限，只能指导少数人
- 经验难以规模化传播

**AI时代的矛盾：**
老师需求变了，教研员还在用老方法

### 3.2 教研员的三个新角色

**角色1：体系构建者**
- 把教研经验变成可复用的框架
- 把名师案例变成可调用的知识库
- 把评价标准变成可执行的规则

**角色2：资源组织者**
- 核心资产：名师课堂数据库
- 按知识点分类的视频片段
- 可检索的教学设计案例
- 可调用的教学方法库

**角色3：生态设计者**
- 设计完整闭环：备课→上课→评课→改进→沉淀
- 让AI、老师、数据形成生态
- 让优秀成果规模化复制

## Part 4：如何落地

### 第一步：转变评课方式
- 从监控式评课到支持式教研
- 让老师主动使用，而非被动上传
- 建立"问题→建议→改进"闭环

### 第二步：构建完整闭环
- 备课教研：看老师如何用AI设计认知路径
- 听课教研：看AI在哪些环节真正起作用
- 评课教研：基于AI分析+名师对比给改进路径

### 第三步：体系化沉淀
- 收集整理本区优质课（按知识点分类）
- 梳理优秀教师经验（形成可复用框架）
- 培训老师使用方法（如何让AI成为生产力工具）

### 能做出什么成果？
- 区域：建立AI时代教研体系，形成示范
- 学校：教师会用AI提升教学，新教师快速成长
- 教师：备课质量提升，随时得到支持
- 教研员：从经验型到体系型跃迁，价值放大

**AI评课系统，真的能帮我们更好地做教研吗？**

答案是：取决于我们把它当成监控工具，还是支持系统。

**AI时代的精准教研：**
- 不是精准评价，而是精准支持
- 从理解老师真实需求开始
- 重新设计教研方式
