## 「AI通过追问帮学生定位思维断点」

> 对应章节：3.6.2 课后错题——教学生跟AI做一次思维诊断
>
> 截图目标：展示AI如何通过追问，把"阅读理解答错了"这种笼统感受，
> 定位到"在分析'表达作用'类题目时，只写出了内容层，没有写出效果层"这么精准。

## 操作说明

**第一步：把下面这段话复制，发给 Claude**

这模拟的是：学生拿着一道做错的阅读题，按老师教的方法跟AI对话。

---

```
我做错了这道语文阅读题，想请你帮我找到我真正卡在哪里。

【原文片段】
秋天的黄昏，落叶铺满小路，风一来，叶子就打着旋儿飘起来，像一群蝴蝶。
远处有炊烟升起，模糊在暮色里，只剩下一个淡淡的轮廓。

【题目】
划线句"像一群蝴蝶"使用了什么修辞手法？有什么表达效果？（4分）

【我的答案】
使用了比喻的修辞手法，把落叶比作蝴蝶，写出了落叶被风吹起来旋转飞舞的样子。

【标准答案】
使用了比喻的修辞手法，把落叶比作蝴蝶，生动形象地描绘了落叶在风中轻盈飘飞、姿态优美的动态画面，表达了作者对秋天景色的喜爱与留恋之情。（内容2分+效果2分）

我当时的思路是：看到"像"就知道是比喻，然后解释比喻的本体和喻体是什么，再说说描写了什么画面，感觉答得挺完整的，但只得了2分。

请不要直接告诉我正确答案。先问我几个问题，帮我自己找到我到底卡在哪一步。
```

---

**第二步：等AI问了几轮问题之后，继续发这句话**

```
好，现在告诉我：我的思维断在了哪一步？
修复这个断点，我应该先做什么——是重新理解这个答题框架，还是直接多做几道练习题？
```

## 预期AI会问的追问方向（供参考，不用提前看）

AI通常会问：
1. "你觉得你的答案里写了什么？"→ 引导学生发现自己只写了"是什么"
2. "标准答案比你多写了什么？你看得出来吗？"→ 引导学生发现"效果层"
3. "你知道'表达效果'和'描写内容'有什么区别吗？"→ 定位概念混淆点

最终诊断应该类似：
> "你的思维断在了'答修辞效果题'的第二步——你知道要说'用了比喻，把X比作Y'，也知道要说'描写了什么画面'，但你没有意识到还需要第三步：说这样写**让读者感受到了什么**，或者**表达了作者什么情感**。这不是粗心，是你的答题框架缺了一层。"

## 为什么选这道题（供你写书时参考）

这道语文阅读题是理想的示例，因为：

1. **学生的错误很典型**：不是算错了、不是完全不会，而是"感觉答得挺完整但就是少分"——这种模糊的错是最难自己定位的
2. **思维断点很清晰**：就是漏了"效果层"，AI追问几轮就能帮学生自己发现
3. **对比冲击强**：老师改卷只能写"答案不完整"，但AI能追问到"你在哪一步停下来了"
4. **跨学科可迁移**：语文阅读的"内容层+效果层"这个答题结构，历史的"直接原因+根本原因"，英语作文的"语法正确+表达地道"，都是同一类思维断点——学生知道有答案但不知道差在哪
