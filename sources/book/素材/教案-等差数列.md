# 教案：等差数列的概念与通项公式

**学科：** 高中数学（必修5）  
**课题：** 等差数列的概念与通项公式  
**年级：** 高一  
**课时：** 1课时（45分钟）  
**执教教师：** ——

---

## 一、学情分析

学生在初中已接触过简单的数列（如奇数列、偶数列），对"按规律排列的一列数"有直观感受，但没有系统学过数列的研究方法。进入高中后，本节是他们第一次用代数语言描述"规律"。

本班学生的特点：
- 直觉较好，能发现简单规律，但抽象表达能力弱
- 习惯被动接受结论，主动发现规律的经验少
- 对"公式推导"普遍有抵触，觉得枯燥

因此，本节的核心挑战不是"让学生记住公式"，而是**让学生经历"发现规律→表达规律→验证规律"的完整过程**，使公式不再是"死记的符号"，而是"自己推出来的结论"。

---

## 二、教学目标

1. 能识别一个数列是否为等差数列，理解等差数列的本质特征
2. 能用自然语言和代数符号两种方式描述等差数列的规律
3. 自主推导出等差数列通项公式 \( a_n = a_1 + (n-1)d \)
4. 能用通项公式解决简单的求项、求项数问题

---

## 三、教学重难点

**重点：** 等差数列的定义，通项公式的推导  
**难点：** 从具体数列中抽象出"公差"的概念；理解通项公式的推导逻辑（累加法）

---

## 四、教学过程

### 环节一：创设情境，引发观察（约8分钟）

**教师活动：**

在黑板上写出以下三组数：

```
A：2, 5, 8, 11, 14, 17, ...
B：100, 90, 80, 70, 60, 50, ...
C：1, 2, 4, 8, 16, 32, ...
```

**提问1（开放性）：**  
"你能发现这三组数各自有什么规律吗？用自己的话说说看。"

（给学生1分钟独立思考，再请2~3人作答。）

**预期学生回答：**  
- A组：每次加3
- B组：每次减10
- C组：每次乘2

**追问2（聚焦差异）：**  
"A和B很像，C和它们有什么本质不同？"

**预期回答：** A、B是加减操作（加固定数），C是乘法操作。

**教师引导：**  
"A和B有一个共同特征——相邻两项的**差**是固定的。我们今天就来研究这种数列。"

> **设计意图：** 让学生自己观察并说出规律，而不是由教师直接告知。C组数列作为反例，帮助学生主动区分"等差"和"等比"，埋下后续学习的伏笔。

---

### 环节二：建立定义，精确描述（约10分钟）

**提问3（语言转换）：**  
"刚才你说A组'每次加3'，能不能用数学语言更精确地说出来？"

（引导学生从"相邻两项"出发，尝试用符号表达。）

**板书引导过程：**

```
用 a₁, a₂, a₃, ... 表示各项
A组：a₂ - a₁ = 3，a₃ - a₂ = 3，a₄ - a₃ = 3 ...
规律：aₙ₊₁ - aₙ = 3（固定值）
```

**提问4（提炼定义）：**  
"如果这个固定值不是3，而是任意一个常数d，那么满足这个条件的数列叫什么？你觉得应该怎么给它下定义？"

（学生尝试自己说出定义，教师规范语言。）

**板书定义：**

> 一般地，如果一个数列从第二项起，每一项与它前一项的差都等于同一个常数，这个数列就叫做**等差数列**。这个常数叫做等差数列的**公差**，通常用字母 \( d \) 表示。

**提问5（辨析理解）：**  
给出以下数列，请判断哪些是等差数列，哪些不是，并说明理由：

```
① 3, 6, 9, 12, 15, ...
② 1, 1, 1, 1, 1, ...
③ 1, 2, 4, 7, 11, ...
④ 5, 5, 5, 5, 5, ...
```

（请学生逐一判断并给出理由，特别追问②和④——公差为0的等差数列是否合法？）

> **设计意图：** 通过辨析题，让学生检验自己是否真正理解了"每一项与前一项的差为同一常数"，而不是停留在"看起来有规律"的模糊印象。②④是坑：公差为0也是等差数列，很多学生会直觉上排除。

---

### 环节三：推导通项公式（约12分钟）

**提问6（引发需求）：**  
"等差数列 2, 5, 8, 11, ... 的第100项是多少？你能算吗？"

（学生意识到一项项加下去不现实，产生"需要公式"的真实需求。）

**提问7（找规律）：**  
"把前几项写出来，你能看出 \( a_n \) 和 \( a_1 \)、\( d \)、\( n \) 的关系吗？"

**引导学生观察：**

```
a₁ = a₁
a₂ = a₁ + d
a₃ = a₁ + 2d
a₄ = a₁ + 3d
...
aₙ = a₁ + ?
```

（让学生自己填出最后一行。）

**提问8（严格推导）：**  
"你'看出来'的这个结论，能不能用更严格的方式证明它一定对？"

**引导累加法推导：**

```
a₂ - a₁ = d
a₃ - a₂ = d
a₄ - a₃ = d
...
aₙ - aₙ₋₁ = d

把这(n-1)个等式全部相加：
aₙ - a₁ = (n-1)d
∴ aₙ = a₁ + (n-1)d
```

**板书通项公式：**

$$a_n = a_1 + (n-1)d$$

> **设计意图：** 先让学生"猜"出公式，再引导他们"证"出公式。这两步都不省略——猜出来是直觉，证出来是理解。学生经历了完整的发现过程，公式不是"记来的"而是"推出来的"。

---

### 环节四：应用练习（约10分钟）

**例题1（直接套用）：**  
等差数列的首项 \( a_1 = 3 \)，公差 \( d = 4 \)，求第10项。

**例题2（逆向求解）：**  
等差数列的第5项是17，公差是3，求首项和通项公式。

**例题3（开放型）：**  
等差数列中，\( a_3 = 10 \)，\( a_7 = 22 \)，求 \( a_n \)。

（例3不直接给出 \( a_1 \) 和 \( d \)，需要学生先建立方程组，引导他们发现"已知两项也可以确定整个等差数列"。）

---

### 环节五：总结与迁移（约5分钟）

**提问9（回顾结构）：**  
"今天我们是怎么一步步得到等差数列定义和公式的？你能把这个过程说出来吗？"

**引导学生复述：**

1. 观察具体例子，发现规律（直觉）
2. 用数学语言精确描述规律（定义）
3. 用辨析题检验理解是否准确（辨析）
4. 发现需要"算远处的项"的需求（动机）
5. 观察规律→猜出公式→严格证明（推导）

**教师结语：**  
"这不只是等差数列的学习方法——这是数学中研究'规律'的一般路径：观察→抽象→验证→推导。下次遇到新的数列，你可以用同样的思路去研究它。"

---

## 五、板书设计

```
等差数列

定义：aₙ₊₁ - aₙ = d（d为常数）

通项公式：aₙ = a₁ + (n-1)d

推导方法：累加法
  a₂-a₁=d
  a₃-a₂=d    → 相加 → aₙ-a₁=(n-1)d
  ...
  aₙ-aₙ₋₁=d
```

---

## 六、教学反思（课后填写）

本次课设计的核心思路是：**不直接给出定义和公式，而是让学生在"观察→辨析→推导"的过程中自己建构知识。**

每个环节都有一个核心问题驱动，学生不是在听讲，而是在思考和回答。公差的概念、通项公式的推导，都不是教师说出来的，而是学生在追问中自己说出来的。

这种方法对教师的要求较高：需要精心设计问题的递进顺序，每个问题都要在学生能够回答的"最近发展区"内。设计不好，学生会卡住；设计太简单，学生不需要思考。
