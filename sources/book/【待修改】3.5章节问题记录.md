# 3.5 章节待修改问题记录

## 问题一：3.5.1 提示词内在矛盾（分层逻辑需调整）

**位置**：第二部分 → 3.5.1 不分快慢班，用三种角色让不同学生都有事做

**当前提示词**：
> 初二英语阅读课，课文是关于环境保护的文章。我的班级大概分三个层次：A层（约10人）词汇量大，阅读能力强；B层（约20人）基本能读懂，深层理解需要引导；C层（约10人）词汇量不够，读原文有困难。你能帮我设计一个分层方案吗？三个层次的学生都要有事做、都能有收获。特别注意——不要让C层学生觉得自己被"区别对待"了。

**问题**：
- 提示词按"能力缺陷"定义学生（词汇量不够、需要引导、能力强），然后加约束"别让人觉得被区别对待"
- 这两件事方向相反：一边强调能力差距，一边要求假装没差距，AI会给出尴尬的"看起来不分层但实际还是按能力分"的方案
- 真正的角色分层逻辑应该是：这个任务需要哪几种不同视角/贡献 → 不同学生的特点对应哪种角色 → 每种角色缺一不可

**建议修改方向**：
把负向约束（"不要让人觉得被区别对待"）改成正向设计目标（"每个角色缺一不可"），把能力描述从缺陷视角改成贡献视角，并明确要求设计"成果汇合"环节。

**建议提示词**：
```
初二英语阅读课，课文是关于环境保护的文章。

我想用"角色分工"而不是"难度分层"来设计这节课——
让全班学生共同完成一个有价值的任务，每个人承担不同的角色，
每个角色都是任务不可缺少的一部分。

班级情况：
- 约10人阅读能力强，能做深度分析和评论
- 约20人能基本理解文章，适合做观点梳理
- 约10人词汇量有限，但能做信息提取和关键事实整理

请基于这篇环保文章，设计一个角色分工方案：
1. 三种角色各是什么？每种角色做什么？
2. 最终全班如何把三种角色的成果汇合成一个整体？
3. 每种角色在汇报时能展示什么"别的角色做不到的"价值？
```

## 问题二：3.5.2 概念误导（技术实现与描述不符）

**位置**：第二部分 → 3.5.2 更大胆的做法：给每个学生一个专属的AI学习搭档

**当前描述**：
> 她让AI帮她做了一个简单的"阅读小助手"……上课时，C层的学生每人手机上多了一个"阅读小助手"。碰到不认识的词，问一下就行……

**问题**：
1. **技术诚信问题**：一个单机HTML页面做不到真正的AI对话。书里描述的"AI会用中文解释词意"在静态HTML里根本不存在，读者照做必然踩坑。
2. **概念错位问题**："给每个学生一个专属AI学习搭档"暗示AI能实时感知学生状态并个性化响应——这是Agent级别的能力，不是一个HTML页面能做到的。
3. **设计逻辑问题**：仅针对C层、仅用于上课时词汇解释，格局太小。真正有价值的是设计一套课后自主学习系统，所有学生都能用，老师规划好路径，学生按自己节奏走。

**建议修改方向**：
把3.5.2改为"课后：用AI为学生设计一条学习路径"，框架参考《用AI为学生搭建一个自主学习系统》（见 前期准备/公众号/教学系统的设计/系列03 场景B的设计/）

**核心逻辑重构**：
- 课堂上解决"分角色"问题（3.5.1保留）
- 课后：老师作为**学习路径设计师**，用飞象老师等工具做一个HTML学习系统
- 系统包含：知识讲解 → 关键练习 → AI协作提示（具体告诉学生"此刻可以这样问AI"） → 费曼讲解检验
- 不分ABC层，所有学生都能用，每人按自己节奏走
- 技术实现上诚实：是飞象老师这类工具生成的有AI接入能力的系统，不是静态HTML

**配套HTML**：
已单独设计一个演示HTML（见同目录 `3.5-差异化教学演示.html`），可作为书中配图或读者参考示例。
