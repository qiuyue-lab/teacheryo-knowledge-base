## 图6-1 截图素材
### 「AI教研员引导式教学反思：从了解情况到改进建议」

**复制以下内容发给 Claude：**

---

```
请你扮演一位资深的初中历史教研员，帮我做教学反思。

你需要做到：
1. 先了解我的情况，再给分析
2. 从教学逻辑、认知负荷、活动设计、时间分配等多个维度分析
3. 结合名师在类似课题上的做法，给我具体的参照
4. 给出具体、可操作的改进建议

以下是我的信息：

【课题】甲午中日战争——原因、经过与影响
【学段】初二历史
【教学目标】让学生理解甲午战争失败的根本原因不是武器落后，而是制度腐败和战略失误；同时能从这场战争中读出近代中国面临的深层危机
【主要环节】
1. 导入（5分钟）：展示北洋水师和日本联合舰队的装备对比图
2. 新授（20分钟）：讲战争经过，重点讲黄海海战和平壤战役
3. 活动/练习（12分钟）：小组讨论"中国为什么会输"
4. 小结（3分钟）：梳理影响，引出《马关条约》

【实际上课情况】
- 跟计划不同的地方：讲战争经过时细节太多，新授用了28分钟，小组讨论只剩4分钟
- 学生的反应：听战争经过时还比较专注，但讨论"为什么输"时大部分学生只说"武器不行""军队腐败"，很难深入

【我的感受】
- 觉得不太顺的地方：感觉学生把"原因"和"结果"混在一起了，讨论没有层次
- 不确定的地方：这个问题本身是不是太难了？还是应该给更多支架？

请先确认你理解了我的情况，然后再开始分析。
```

---

**截图建议：**
- 截取 Claude 的完整回复（通常包括：①确认理解 ②多维度分析 ③名师参照 ④改进建议）
- 重点截取"多维度分析"和"名师参照"部分，这是图6-1要展示的核心
- 如果回复很长，可以只截"分析框架"那段（从"从以下几个维度分析"开始到"改进建议"结束）
- 窗口建议调窄一点（约800px宽），这样截图在书里更好排版

## 图6-2 截图素材
### 「3分钟快速复盘：简短描述即可获得多维分析与改进建议」

**复制以下内容发给 Claude：**

---

```
我刚上完一节课，请以教研员的角色帮我快速复盘。

课题：初二历史，甲午中日战争
我觉得最不顺的一个环节是：小组讨论"中国为什么会输"
具体表现：学生讨论只停留在"武器差""腐败"这个层面，说不出更深的原因；几乎没有小组提到制度问题或战略决策失误，讨论4分钟就陷入沉默

请帮我：
1. 从至少3个角度分析这个环节"不顺"的可能原因
2. 如果有名师在类似课题上的做法，给我做参照
3. 给出2-3个具体的调整方案
```

---

**截图建议：**
- 这个回复会比图6-1短很多，截完整回复即可
- 重点是展示"3个角度分析"那部分——这是和传统反思"太笼统"的核心对比
- 如果AI给了名师参照，那段要保留在截图里
- 截图时把提示词也一起截进去（上半部分是提示词，下半部分是AI回复），更直观展示"3分钟复盘"的感觉

## 两张图的配合逻辑（供你写书时参考）

| | 图6-1 | 图6-2 |
|---|---|---|
| 对应提示词 | 详版（填写整节课信息） | 简版（只说最不顺的一个环节） |
| 展示重点 | AI如何"先理解再分析"，体现教研员的引导方式 | 同样是AI分析，但3分钟能做到多维 |
| 对比传统反思 | 有框架、有参照、有具体建议，不是"写了等于没写" | 2-3句描述 → 多角度分析，门槛低，日常可用 |
| 书里的作用 | 展示"深度反思"的完整效果 | 展示"低门槛日常用法" |

这两张图放在一起，传递的信息是：AI教研员有两个用法——深的时候能做全面复盘，快的时候3分钟也能有收获。老师可以根据自己当天的时间选择用哪个。
