# 学英语放马屁：用腾讯秒搭 2 小时做出一款"横版跑酷 × 英语阅读"小程序

> **分享人**：Cecilia 陈老师（需求 / 文本 / 视频）× 蒙其军老师（技术 / 开发）
> **时间**：2026 年 4 月 18 日 黑客松后续系列分享
> **主题**：针对"带一个人读懂一篇读不下去的东西"这个题目，把超级马里奥式跑酷游戏 + 英语阅读拆解 + 学习锦囊融合成一款小程序

---

## 一、怎么解题：先打架，再对齐

两位老师拿到题目"带一个人读懂一篇读不下去的东西"后，一开始方向完全不同。

- **Cecilia 的方案**：直接用龙虾（小龙虾 / Claude Code）跑了一个"引导式阅读体验"小网页——类似"阅读登山径"，带路标、能量站、山顶瞭望台，把难读的内容拆解成故事，引导用户一步步读下去
- **蒙其军的否定**："你这个东西太无聊了。读不下去就是要玩。"
- **转折点**：蒙老师展示了他之前做的"小马"——一个横版跑酷式的英语小游戏

那一刻 Cecilia 被打动了：**所有孩子都爱玩游戏，这是比任何阅读设计都更通用的"兴趣入口"**。

### 为什么选英语不选文言文
- Cecilia 是语文老师，本想做文言文
- 但文言文要重新搓一遍素材，时间不够
- 英语有现成的原型可以做二次开发
- 目标人群：小学生（也能扩展到初中、高中、大学甚至科研英文文献）

### 取名也改了很多版
"彩虹小马学英语"→"彩虹放屁小马学英语"→最后定名 **"学英语放马屁"**。蒙老师在取名上的直觉是——**越不走寻常路越吸引人**。

## 二、产品设计：游戏与学习的"辅助"定位

### 游戏灵感来源
蒙老师小时候玩超级马里奥长大，后来做老师时发现一个英语特别差但极爱玩游戏的学生，就把"跑酷+背单词"结合做了个原型。黑客松把这个原型升级成——**既能记单词，又能辅助读一篇文章**。

### 核心玩法
- 顶部：上传自己想读的英语文章
- 系统自动分析句子、提取重点词汇
- 下半屏：横版跑酷式闯关，在游戏里完成拼写与理解

### 关键改良 1："朗读"功能（群友提出）
关卡结束时，自动朗读对应的英文单词和句子。

### 关键改良 2："学习锦囊"功能（群友提出"过于娱乐化"后加的）
群友反馈说这款应用更像游戏而不是学习工具，于是加了学习锦囊：
- 选错时自动弹出单词释义
- 点击锦囊可以查看当前句子的所有重点词汇 + 英语发音 + 词汇解析
- 通不了关时允许合理调用，**"辅助学习 > 游戏"的定位由此确立**

### 小插曲：蒙老师另一个作品《别踩李白》
李白所有诗词分三等级（静夜思→将进酒、蜀道难），玩法模仿"别踩白块"——**错误方块就是李白**，所以叫"别踩李白"。群里不少老师对这个感兴趣，适合初中古诗词背诵训练。

## 三、技术分享：用腾讯秒搭 AI Coding 搭小程序

### 为什么选秒搭
- 月费 9.9 元，一个月做 1-2 个应用够用
- 可以直接生成**微信小程序**，方便分发
- 完全自然语言驱动，零代码门槛

### 制作流程 Step by Step

**Step 1：写创意一句话**
> "我想做一个帮助学习英语的游戏"

**Step 2：点击「指令优化」**
秒搭自带一个功能——把你写的自然语言自动扩写成结构化提示词，AI 更好理解。

**Step 3：选风格**
比如"怀旧像素风"（对应超级马里奥那种视觉）。

**Step 4：选插件**
- 微信小程序登录插件（加了之后学生必须登录才能玩，后台有数据记录）
- 排名插件
- 视频生成 API、百度地图 API、搜索 API 等任何需要的服务
- **用法很简单**：点一下插件 → 在需求描述里写"我要在游戏胜利时生成一个庆祝动画"，API 就接好了

**Step 5：上传生成 → AI 反馈核心功能拆解**
秒搭会输出：核心学习目标、游戏化机制、单词拼写关卡……不符合的可以勾掉。

**Step 6：用"自然语言 + 需求文档"迭代**
- 小马的动作、跳跃姿势、甚至"放马屁臀部烟雾"这种卡通动画，全部是**通过文字描述让 AI 调出来的**
- 飞书里维护一份**需求文档**，里面详细列出每个核心功能、交互动作、每一次迭代的改动
- **群友体验完就提改进意见，当场迭代**

### 外部 API 接入
- 以前做计算机开发要写大量代码对接 API
- 现在 AI Coding 时代，"点一下插件"就完成，甚至用小龙虾（Claude Code）直接自然语言就行
- 视频生成、百度地图、搜索……全部一键接入

### 描点机制
程序做得好可以共享出去，别人点赞会让你的"描点"增加——这是秒搭社区的反馈激励。

### 秒搭 vs 扣子 vs 飞象（TeacherYO 追问）
| 工具 | 擅长 |
|---|---|
| **秒搭** | 小程序、小游戏，一键分享到微信 |
| **扣子（豆子）** | 智能体；PPT 做得非常好看 |
| **飞象** | 课堂情境化导入、小互动游戏，html 生成目前最强 |

TeacherYO 顺便提到飞象的产品方向：**内化**——不需要用户写精细提示词，模型能自动识别"你要做哪节课、什么学科、什么模型"，直接出结果。长期看，html 是过渡形态，**最终大家需要的是应用 / Agent，并且真正核心的是"分发"**。

## 四、Cecilia 的数字人微课：有言

很多老师对 Cecilia 之前发在群里的**数字人宣讲视频**感兴趣，她顺便安利了"有言"。

### 为什么推荐有言
- 场景非常好看（相比其他数字人平台）
- 操作简单
- 支持文本→口播视频 / PPT→视频 / AI 脚本三种入口
- 横屏（课堂教学）和竖屏（自媒体）都可以

### Cecilia 的"学英语放马屁"宣传片制作流程
1. 把需求文档丢给有言
2. 选择"从 PPT 开始创作"
3. 有言自动生成 PPT
4. 自己加简介
5. 选场景、选主屏
6. 输出视频

整个过程几乎只是"把文档扔过去 + 做一点微调"。

## 六、最值得带走的认知

1. **游戏化学习的精髓不是"在学习里加游戏"，而是"让游戏本身成为学习的容器"** —— 从超级马里奥的横版跑酷这个孩子已经无比熟悉的形式切入，学习的门槛自然降低
2. **秒搭 = 零代码 × 小程序原生 × 微信生态分发**，是老师做 AI 教学工具最轻的路径之一
3. **需求文档（飞书维护）+ 群友众测 + 快速迭代**，是 AI Coding 最朴素也最有效的工作流
4. **学习锦囊**这种设计是防止"游戏化滑向纯娱乐"的关键保险——定位是"辅助学习工具"，而不是"教育游戏"
5. **取名要敢于跳脱主流**。"学英语放马屁"这种看似荒诞的名字，反而比"彩虹小马学英语"更能打穿用户
6. **API 时代工具论**：点一下就能接入百度地图 / 视频生成 / 微信登录 —— 老师不需要懂代码，只需要知道"我要什么结果"
7. **数字人 + AI PPT = 微课宣传片工业化**，老师可以用这套工具给自己的作品做专业传播
8. **html / 小程序只是过渡形态**，最终会走向"应用 / Agent + 原生分发"
