## 第1期：AI学舍项目——教师备课助手（止水）

止水分享"AI学舍"——基于 Obsidian + Cursor 的预制仓库系统，面向师生两端。Obsidian 做前端笔记，Cursor 做 AI 后端，打开同一个本地文件夹，数据全部留本地不上云。三个关键概念：**Skills**（渐进披露的预制提示词工作流，用时才加载）、**预制仓库**（首次打开引导式初始化，按年级学科自动生成知识库骨架）、**归档规则**（导入资料时 AI 按 skill 自动分类存放）。现场从零跑通了学生端仓库初始化：环境检测→加载 skills→生成结构→导入资料→自动归档。计划做成"半开源"项目，让更多老师直接拿来用。

## 第2期：Rolex框架——AI教师学校演示（岳秋）

岳秋用 Rolex RDD 框架现场搭建一所"AI 教师学校"。主线：**女娲**建组织并明确使命→创建"校长优"角色（融合 TeacherYo 与李希贵特质）并注入办学理念→切**姜子牙**做战略咨询讨论学习旅程→再换角色做矛盾分析交叉审核。三点关键：①**三重实体**——角色、组织、岗位（角色可被 hire 到组织、appoint 到岗位，不同岗位注入不同 duty）；②**学习旅程三阶段**——破冰（认知觉醒）/实践（能力提升）/进化（系统构建），每阶段配引导型、陪练型、方法论型 Agent；③**角色交叉验证**——让不同角色相互批判，规避大模型"谄媚"。结论：培训课程只是辅助，核心是为每个阶段设计陪伴教师学习的 Agent。

## 第3期：命题流程解析——高考能力点标注系统（炎鑫）

高中历史老师炎鑫用一个多月做了一套用 AI "拆穿"高考题的能力点标注系统。起点是课标"学业质量水平"，拆成维度→提点→**微提点**（单独能独立出一道题的最小粒度，山东卷历史可拆 150+ 个，高频核心 44 个）。双向验证：课标提炼能力点 × 真题反查映射，再横向对比各省卷命题偏好。40 步工作流由一个 AI 角色按清单跑，上一步输出即下一步输入；**血泪教训**：最初用 Skill 跑，会"削足适履"硬套库，换成**角色**后 AI 有了判断力，输出质量飞跃。最终产出三库：命题技术库、读点模式库、思维模型库。六种思维模型（提取/整合/排序/穿透/映射/压缩）可让同一材料生成六道不同层次的题，定向补训学生思维卡点。

## 第4期：Vibe Coding 实战——Claude Code 全流程与知识库搭建（正己）

语文老师出身的正己把 Vibe Coding 完整链路走了一遍。**环境配置**用"AI 是实习生"比喻串起 Node.js / Git / Claude Code / API。**管好 AI**：Hooks 是 100% 强制执行的自动化规则（删文件自动拦截等），CLAUDE.md 是 AI 每次干活必读的员工手册。**Oh-my-claude 插件**给 Claude Code 加 buff——省 token、自动拆任务并行、持久执行，team 模式可一次开 15 个子智能体。**Stitch**（Google AI UI 工具）文字或草图直出网页稿，可导 Figma 或转小程序。**数据清洗双线**：基于 RAG（Markdown + 标签摘要提召回）和传统数据库（SQLite + MCP "点菜式"查询，防上下文撑爆）。金句："先让 AI 问你问题再设计方案——先对齐需求，再动手。"

## 第5期：极简备课——手机备课工作流搭建（少川）

初中语文老师少川（十月龄娃的妈妈）80% 时间陪娃，摸出了一套手机就能跑的极简备课法。底层原则：**奥卡姆剃刀，如无必要勿增实体**，有重复真实需求再上工具。框架是"两种起点一个终点"：①已知想要什么——从自己备得最好的几节课里提取固定元素，固化成提示词，用 **Dify 聊天助手**调用（现场演示融合高圣远/戴建业/欧丽娟风格的古诗词备课助手）；②不知道想要什么——和 AI 聊你认同哪位名师、能驾驭哪种讲法，慢慢找固定元素再回到路径一。工具链：Dify + MiniMax/Kimi Code；进阶版加腾讯云轻量服务器（99/年）部署 Open Cloud 接 Telegram/QQ，手机发一句话云端出教案。金句："好的提示词不是靠模型厉害，是靠你把流程想清楚了。"

## 第6期：如何让 AI 成为你的实用新同事（岳秋 + 江山 Sean）

社群第一次明确以"道"为主轴。岳秋把认知框架从"使用 AI"扭到"与 AI 协作"——别把 AI 当助理（工具/单向使用/比你弱），要当**同事**（角色/平等协作/可能比你厉害）。现场用**女娲**为南诗懿老师"招聘"培训设计师：岗位招聘→入职培训（把组织理念转化成角色能内化的知识格式注入）→技能训练（让角色从实践中沉淀经验）。对比**姜子牙**：女娲适合快速搭出可用角色，姜子牙适合深挖并生成"认知模式"模块。演示把名师捏成分身时强调——只提"上课步骤"是 skill，挖到教学信念和价值判断才是 **principle**，后者才让分身真正"像那个人"。下半场 Sean 演示新版 Skill 系统：GitHub 远程加载、干完活可自动沉淀新 Skill 并云端共享。

## 第9期：分层探究科学实验——《摆的研究》无痕分流课堂（三水 × Alice · 04.16）

三水（美术）+ Alice（科学）交付的不是"分层测验系统"，而是一堂小学 5 年级的**无痕分流探究课**。核心主张：真正的分层不应让学生感到被贴标签。**三个"无感"设计**：四道题含自我认知题完成降档分层、路径可"串门"但有思维墙、汇报看板一模一样保护尊严。**三条脚手架**：A 类完全自主设计、B 类有结构化表格、C 类先用提问卡+模拟器理解"什么是摆"——刻意不给柱状图，让学生从原始数据自己发现规律，并加随机噪声训练真实科学素养。**多模型协作**：GPT 粗 PRD → Claude 4.6 "拷问"PRD（让 AI 自提 10 个尖锐问题并排序）→ Claude Code 开发。Alice 金句：**"UI 用 Gemini，编程用 Claude Code"** + **"PRD 搞定，后面都可以慢慢搞。"** AI 只做 40-50%，剩下全是老师的教学判断。

## 第10期：文言文翻译官——10步引导式拆解与后端部署（Iris × 雷君 · 04.16）

Iris（语文）+ 雷君（技术）做了一个水墨风、**10 步引导式**的文言文翻译官网页，接即梦 API 点句即出水墨意境图。10 步锁"心流"：原文切换/通假字/古今异义/一词多义/词类活用/句式/虚词/背景/情感主旨/导出笔记——每步必须参与才能点下一步。Iris 踩坑：一次给 Cursor 塞太多功能（读音+词性+释意）直接跑不出来——**需求拆小，核心先跑通再加**。真正硬核是后半段：雷君指出老师做 AI 产品的终极门槛是**后端**（服务器/登录/留痕）。推荐**扣子（Coze）**一键部署、9.9/月基本够一个班用。TeacherYo 点题：HTML 是过渡，**Agent 化才是方向**；但 **API 的钱谁出**仍是老师自制 AI 产品规模化的核心障碍。

## 第11期：用 Promptx 多角色协作捏"小学数学备课导师"（岳秋 × 严菜 · 04.16，彩蛋）

严菜（小学数学）只和女娲对话，结果越调越糟。TeacherYo 当场诊断：**跳过了"搭架构"这一步**，结构从一开始就没立住。Promptx 的底层不是提示词，是**AI 组织架构**：女娲是 HR 造人，姜子牙是架构师+矛盾分析，TeacherYo 分身懂教育，Sing 是矛盾论专家。正确工作流：**姜子牙搭架构 → 专业角色提反对 → 女娲最终生成**，分工不能乱。现场 6 步从 0 捏出"小蔡"导师并真实场景测试（北师大版四下《小数点搬家》）。**6 条原则**：①专业度决定角色上限 ②要抽象不是堆资料（喂几百篇公众号反而抽不出东西）③核心理念 > 知识库 ④模型×架构×设计缺一不可 ⑤反思机制让角色会成长 ⑥追问比描述更重要。

## 第12期：破案式个税沉浸学习——Codex superpower 与人机协作原则（张思嘉 × Lasso · 04.17）

张思嘉把老师 6 月要报的"个税累计预扣"做成了剧本杀式沉浸课。核心武器是 **superpower skill**：挂 Codex 后 AI 收到指令不立刻动手，反过来**追问十几轮**对齐才写，每问给 1/2/3 推荐可任意组合。顺手一招：用"**占位符**"工作流解 AI 改 Word 教案字体错乱——模板上标占位→Codex 生成结构化提示词→分节点生成。Lasso 的重点不是操作是理念，4 条人机协作原则：**判断力**（你的经验是有重量的）、**感觉**（具身认知比 AI 文字处理更可信）、**目标感**（你没把住目标 AI 一定走偏）、**直觉**（AI 的训练集就是"已有的框架"）。3 个坑：选项焦虑、只想"怎么做"不想"做什么"、把过程当成果。金句：**"你连自己的感觉和判断都不信，就别用这工具了"** + "人要比 AI 凶"。

## 第13期：桌宠小咕噜——用好奇心驱动幼儿项目化学习（俞坚 × 希希 · 04.17）

俞坚（幼教）+ 希希（技术）的"小咕噜"是一只装在教室电脑里的桌面小宠。评委提醒方向稍偏——俞坚开场就坦诚回应"**你的天花板就是你的目标**"。真问题不是炫技，是帮老师**抓住幼儿转瞬即逝的小疑问**——PBL 主题审议的起点。两个关键设计：**不直接给答案**（苏格拉底式回抛，直接告诉答案对幼儿学习有害）+ **形象要可爱到小朋友愿意聊**（Claude Code 最终选出"咕噜"——拟声可爱且隐含"思维滚动"）。希希 **3 步落地法**：场景捋清→技术选型（会的优先）→15 分钟对齐再动手。AI 找资料 3 技巧：用约束条件问、小项目别抄开源让 AI 自写、**85% 的 bug 其实是沟通问题不是代码**。现场演示**Python + Cursor + Ollama 本地大模型**三件套。

## 第14期：大模型的无状态本质——把 Role、Skill、MCP、Agent 讲清楚（江山 Sean · 04.17，彩蛋）

Promptx/Rolex 作者江山用"插电极改记忆"的现场实验把技术、哲学、工程串成一条线。**核心本质：无状态（Stateless）**——每次调用都是第一次，"记忆"全靠每次把完整聊天记录重新塞回去。所以一切**上下文工程都是"拼装上下文"**——只要能任意拼装就能做任意花活。**Role vs Skill**：Skill 本质是死文件（预制菜），Role 借 MCP 动态检测环境实时拼装（现炒菜）。他正在做**永续个体**——不"激活"而是一上来就把身份与记忆拼满，AI 认为它就是它。刘玉强 token 爆的解法三层：反思消冗余→沉淀成 Skill 只留索引→拆多角色，**AI 之间也要用"工单"派活而非自主判断**。带走三句：**大模型无状态·花活都是拼上下文·Skill 是预制菜、Role 是现炒菜、Agent 是那个炒菜的人。**

## 第15期：学英语放马屁——腾讯秒搭 2 小时做横版跑酷×英语阅读小程序（Cecilia × 蒙其军 · 04.18）

Cecilia（语文/需求）+ 蒙其军（技术）交付的"学英语放马屁"是一款**横版跑酷 + 英语阅读拆解**微信小程序。起点先打架：Cecilia 的"阅读登山径"被蒙老师一句"**太无聊，读不下去就是要玩**"否掉，转用他之前的"小马"原型二改——**游戏才是最通用的兴趣入口**。关键设计是"**学习锦囊**"（选错弹词义、过不去可合理调用），锁住"**辅助学习 > 游戏**"边界，防娱乐化漂移。技术用**腾讯秒搭**（9.9/月、自然语言直接生成微信小程序原生分发），流程：一句话创意→指令优化→选风格→选插件→迭代。横评：秒搭擅小程序分发、扣子擅智能体+PPT、飞象擅课堂 html "内化"。Cecilia 顺手安利"有言"做数字人微课宣传片。分工哲学：**需求人 + 实现人 + 紧密对话**，2 小时从零交付可分享小程序。
