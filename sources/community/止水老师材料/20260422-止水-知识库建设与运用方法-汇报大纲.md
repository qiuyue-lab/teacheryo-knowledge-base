# 流墨轩知识库建设与运用方法 · 汇报大纲

> **核心论点**：切片系统不是"题库"，而是**教研工厂**。
> 4,080 份原始 MD，通过标准化板块 + 自动化加工链 + 多维重组，
> 已衍生 **8 大应用纵队、多种具体场景、丰富的独立产物**。

> 不是在做题库，做**语文教研的基础设施**——
> **一份切片，五到八处复用**，形成教研素材的长效沉淀。

## 1. 方法论：切片作为"基础设施"（6 分钟）

### 1.1 教研资料的三大痛点
- **孤岛化**：真题埋在几百份 PDF 里，用一次找一次。
- **一次性**：一次教研产出只服务一次课堂，沉淀不下来。
- **人肉化**：命名、归档、拆题全靠记忆，换人即散。

### 1.2 我的解法：**单源多用 + 分层结构 + 协议化**
- **单源**：一份资料只保存一次，放在唯一的"权威家园"。
- **多用**：同一份切片可组装成访谈、讲义、聚合包、游戏数据、DEX JSON……
- **协议化**：命名规范 + frontmatter + DEX 协议，让机器和人类同时能读懂。

### 1.3 三层架构原则
```
01-原始资料  →  02-加工材料  →  04-导出聚合包
 (唯一真源)     (切片 + 9 纵队)     (印刷 / 分发视图)
```
→ **原始资料永不改动，加工层负责复用，聚合层只是视图。**

### 1.4 研发哲学：精准投放 > 产量
> 不堆题量，不打计件工。
> 让一份切片被 5–8 个下游吃透，胜过切出 10 份只吃一次。

## 2. 上游：切片系统的建设（10 分钟）

### 2.1 试卷切片库
- **4,080 份 MD**，8 大板块，三态齐全（原文 / 题目 / 答案）
  ```
  01a-默写  01b-语用  02-社科文  03-文学
  04a-诗歌  04b-文言传记  04c-文言散文  05-写作
  ```
- **命名规范**（可机读）：`{年份}-{届}-{区}-{轮次}-{板块}-{功能}.md`
- **四阶段管线**：板块切片 → 按板块深加工 → 验证 → 聚合装订
- **单一入口**：`exam_cli.py audit / lint / sync`
- **完整度**：模考 98%、真题部分缺失

### 2.2 课本切片库
- **高中**：5 册 199 MD + 27 篇目级 PDF
- **初中**：8 册 87 MD + 8 XLSX + 598 翻译文件（旧版五四制）

### 2.3 DEX 协议（结构化数据层）
- 与 MD 切片**并行不竞争**的 JSON 出口
- 语义化题号：`2026-嘉定-一模-语文-积累-01`
- 下游可驱动：题库检索 / AI 答题机 / 命题分析

## 3. 下游：八大应用纵队（28 分钟）

> **本节是汇报的重头戏**。同一份切片，喂出八条不同的产品线。

### 3.1 纵队一：题库聚类与专项应用（4'）

#### 3.1.1 EMBA 逻辑学真题应用专项 🌟 **跨学科复用典范**
- **定位**：从语文社科文切片逆向扫出逻辑命题
- **规模**：**330 道逻辑题 / 199 卷 / 9 题型 / 12 讲次**
- **母交付**：汇编 + 考频聚类 + 命题趋势预测
- **关键发现**：
  - 推论题 122 道占 37% 稳居主轴
  - 2024 起"论据支持/削弱"翻近 3 倍
  - 2024 非形式谬误集中爆发 5 道
  - 形式符号逻辑六届零命中 → 坚定"应用层优先"
- **价值**：**语文切片喂出了逻辑学讲义的教学体系**

#### 3.1.2 作文题目库
- **309 条**高考题 + **265** 份题目卡 + **100+** Gemini 范文
- Excel 权威库 + 每题双向链到哲学理论卡

#### 3.1.3 华夏风云录（文言实词库）
- **300+ 实词**，从 04b/04c 切片反向抽用例
- 词 → 篇 → 义三层索引，HTML + PDF 检索版

### 3.2 纵队二：文学访谈体系（止水原创）（4'）

> **方法论**：把原文 + 题目 + 答案组合为**穿越采访**，古人/作者亲自回答采分点。

#### 3.2.1 现代文采访间
- 11 篇 26 届作品（刘亮程、赵瑜…）
- 每篇 8–20 页 MD + PDF
- 四阶段：灵魂播种 → 场景构建 → 文本剖析 → 主旨升华

#### 3.2.2 文言文采访间（传记 + 散文合并）
- 8 篇（26 届一/二模），时空穿梭请古人
- 三列采分表强制（题号 / 题目要点 / 核心要点）
- 特殊案例：顾炎武双材料对读，一题跨时代双嘉宾

### 3.3 纵队三：文言翻译库（2'）
- **500+ HTML + 284 PDF**，教师版 + 学生版双轨
- wenyan-maker Skill 批量化：大模型翻译 → 模板渲染 → PDF
- 作讲义插页 / 学生自学 / 聚合包补充 / 商业课件

### 3.4 纵队四：试卷聚合包 + 做成一本书（3'）
- **47 套聚合包**，25/26 届 · 16 区 · 一/二模
- 每套 200–300 页，八板块 + 访谈 + 翻译 + 阅卷反馈
- 双页 PDF、TOC 自动生成、印刷级
- "做成一本书"Skill：封面 + 目录 + 封底一键成册

### 3.5 纵队五：作文流水线（4 阶段）（3'）

```
① 录入题目卡     → essay 卡片 + 审题三步 + 范畴突破
② 哲学卡配套     → 死链扫描 + 反链回填
③ Gemini 生成范文 → 100+ 篇范文库
④ 打包导出课程包  → 8 个混合包到输出库
```
- **全程自动化 Skill 链**
- 与**哲学理论卡库**（模块 A–D + 一/二/三）双向链接
- 下接学生作文库（43 份迭代作文）

### 3.6 纵队六：讲义 + 教学序列（3'）

#### 3.6.1 九部教学序列（课本 × 切片交叉）
| 文体 | 规模 | 覆盖学段 |
|---|---|---|
| 小说 / 散文 / 诗歌 | 68–101 KB | 小学–高中 |
| 文言文 / 议论文 | 95–134 KB | 初中–高中 |
| 说明文 / 新闻 / 戏剧 / 游记 | 45–72 KB | 各学段 |

- 每篇 = 课本原文 + 推导教学要点
- 纵向进阶（某学段学什么）+ 横向对标（本校缺什么）

#### 3.6.2 哲学理论卡库
- **模块 A–D + 模块一/二/三**
- 单卡 `P-{编号}-{哲学家}.md`，含生平 + 观点 + 案例 + 作文考点
- 支撑高中作文范畴突破与立意升格

### 3.7 纵队七：Wiki + 方法论卡（元知识层）（3'）

- **Wiki 体系**：概念库 / 学派库 / 著者库（王阳明 · Adler…）
- **方法论卡**：
  - 文学四层次理论（止水自研）
  - 止水访谈（穿越采访）
  - 范畴突破法
  - 精准投放 > 产量
  - 试卷四阶段流水线
- **从切片到沉淀**：具体实践 → 一般方法 → 可复用知识

### 3.8 纵队八：流墨轩游戏中心 🎮（4'）

> **重新定位**：游戏中心不是独立产品，而是**切片的游戏化出口**。

- **像素风格语文学习平台**，把切片变成关卡
- **已上线 2 板块**：
  - **文学板块**（基于文本四层次）：S1 四层排序 → S2 十二采分点 → S3 三原则匹配 → S4 AI 多选批改
  - **作文板块**（六阶段 20 关）：审题 → 背景 → 范畴 → 大纲 → 归位 → 论证
- **待发 6 板块**：诗歌 · 文言传记 · 文言散文 · 社科文 · 默写 · 语用
- **课本原文入口**（硬规则）：任何做题界面必须可查原典
- **技术栈**：IndexedDB + localStorage + JSON 备份，31 学生档案默认

## 9. 核心观点与 Q&A（2 分钟）

### 💡 核心观点（贯穿全场）
1. **切片不是题库，是基础设施。**
