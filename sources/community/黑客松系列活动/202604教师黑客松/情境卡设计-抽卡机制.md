# 教师AI黑客松 · 情境卡设计

> 抽卡机制：活动开场后，每组抽取一张情境卡，基于抽到的情境 + 自选赛道，100 分钟内做出一个可带走的作品。
>
> 设计原则：
> - 每张卡都是一个**具体的教育场景**，不是抽象命题
> - 不区分体制内/教培/家长——聚焦所有教育者共通的底层问题
> - 四个赛道（HTML 工具 / AI 角色 / Agent 工作流 / 教学 Skill）都能接得住
> - 做出来的东西，下周就能用
> - 每张卡背后藏一个认知推动：不只是"做个工具"，而是"换一个角度想教育"

---

## 10 张情境卡

---

### 卡 1：一个知识点，三种学生

> **情境**：你正在教一个知识点。班里有三种状态的学生同时存在——一种已经会了、开始走神；一种跟得上、但不主动；一种卡住了、越听越迷糊。
>
> 假设每个学生手上都有一台设备（手机/平板/电脑），同一个知识点，同一段时间，你需要让**三种状态的学生都在动脑**。
>
> **你的任务**：选你自己学科里的一个知识点，做一个东西，让这三种学生在同一个课堂里**各自有事干、各自在成长**——而不是让快的等慢的，也不是让慢的被拖着跑。

**背后的认知推动**：因材施教不是口号，也不是"出三套题"。真正的难点是：怎么让不同水平的人在同一个场里，各自有事干、各自在成长。当每个学生手上都有一台设备的时候，这件事第一次变得真正可行了。

**四个赛道怎么接**：
- HTML → 自适应分层学习工具，不同水平的学生打开后自动匹配不同难度的任务
- AI 角色 → 根据学习者回答动态调整难度和引导方式的导学助手
- 工作流 → 输入知识点 → 自动输出三层任务单（挑战/巩固/补基础）+ 每层的引导策略
- Skill → "同一知识点·三种难度·三种引导方式"的教学设计提示词模板

---

### 卡 2：AI 时代的作业设计

> **情境**：你布置了一个作业——可能是一篇读后感、一份实验报告、一组计算题、一段英语作文。第二天收上来，你发现一大半答案"看起来还不错"，但你直觉告诉你：很多人压根没动脑，AI 帮他们写的。
>
> "防 AI"已经没意义了——AI 比抄还快。传统作业正在失效。
>
> **你的任务**：选你自己学科里**最常布置的一种作业类型**，重新设计它——设计一种**允许甚至鼓励用 AI，但学生必须动脑**的作业或学习任务，并做出配套工具。不限学科。

**背后的认知推动**：AI 替代的是产出，替代不了思考过程。真正的问题不是"怎么防 AI"，而是"当 AI 能给出答案的时候，作业的意义到底是什么？"

**四个赛道怎么接**：
- HTML → "AI辅助但思考可见"的作业提交/展示工具
- AI 角色 → 不给答案、只追问"你是怎么想的"的苏格拉底式导学助手
- 工作流 → 学生提交作业 → 检测思考深度 → 生成个性化追问
- Skill → "允许AI但必须动脑"的作业设计提示词模板

---

### 卡 3：出一道好题

> **情境**：期中考试，你要出一道综合题。要求：考的是真正的理解力，不是记忆力；学生没法靠刷题套路得分；改卷的时候能一眼看出学生到底懂没懂。
>
> **你的任务**：做一个东西，帮任何学科的老师从一个知识点出发，生成一道**考理解、考思维、不能靠背诵的好题**，附带评分标准和常见错误分析。不限学科。

**背后的认知推动**：命题是教师最被低估的专业能力。一道好题能暴露学生真正的思维水平，一道烂题只能考记忆。当 AI 能帮你出题的时候，教师的价值变成了"判断什么是好题"。

**四个赛道怎么接**：
- HTML → 输入知识点和考察目标 → 生成"考理解"的题目 + 评分标准 + 常见错误分析
- AI 角色 → 一个"命题顾问"，追问你"你想区分的到底是什么能力"，帮你从模糊的考察意图变成精准的题目
- 工作流 → 知识点 → 生成题目 → 自动附带评分标准和学生常见错误类型分析
- Skill → "从考察能力出发的命题"提示词模板

---

### 卡 4：一切皆可学

> **情境**：你走在路上，看到一栋老建筑，突然想知道它的历史。你刷到一条新闻，里面有个概念你似懂非懂。你孩子指着天上的云问你"为什么有的云是平的有的云是一坨"。你在博物馆看到一幅画，想搞懂它到底好在哪里。
>
> 这些瞬间，都是学习的入口。但大多数时候，你搜一下、看两行就过去了——好奇心来了又走了，什么也没留下。
>
> **你的任务**：做一个东西，能把**任何一个好奇的瞬间**变成一段真正的学习——输入任何东西（一个问题、一张照片、一个概念、一段对话），它能帮你**从好奇到真正搞懂**，而不是给你一个百科式的标准答案。不限主题、不限身份、不限场景。

**背后的认知推动**：学习不是只发生在课堂里的事。人最强的学习驱动力是好奇心——但好奇心的保质期很短，如果不能在好奇的那一刻就把它变成学习，它就消失了。AI 第一次让"随时随地、遇见就学"变成了可能。真正的教育，不是让人坐在教室里学，是让人在任何地方都能学。

**四个赛道怎么接**：
- HTML → 一个"输入任何好奇"的学习工具（输入问题/照片/概念 → 生成探索式学习体验）
- AI 角色 → 一个"万能学习搭子"，你好奇什么就跟它聊，它带你从浅到深一步步探索
- 工作流 → 输入好奇的内容 → 判断领域和深度 → 生成个性化的探索路径（从入门到深入）
- Skill → "把任何好奇心变成一段学习"的引导式提示词模板

### 卡 5：名师是怎么炼成的

> **情境**：你一定见过那种老师——同样的知识点、同样的学生，Ta 教完之后学生就是比别人班理解得更深。你知道 Ta 厉害，但说不清 Ta 到底厉害在哪。是学科功底更深？是提问方式更好？是更会读懂学生的状态？还是对"什么时候该讲、什么时候该等"有一种直觉？
>
> 这些"厉害"如果说不清楚，就没法学、没法传、也没法让 AI 帮上忙。
>
> **你的任务**：先想清楚——在你的学科里，一个名师到底比普通老师**多了什么**？从哪些维度可以拆解？然后，做一个东西，能沿着你想清楚的这些维度，帮助**捕捉、呈现或培养**一个老师的教学能力。

**背后的认知推动**：每个人都能感受到名师和普通老师的区别，但几乎没有人能清楚地说出来"区别到底在哪几个维度上"。这是最难也是最有价值的思考——只有想清楚了维度，才能做出真正有用的东西。AI 不缺执行力，缺的是"沿着什么框架去执行"。这个框架，只有懂教学的人才能设计。

**四个赛道怎么接**：
- HTML → 一个"名师能力拆解"工具——帮老师沿着你设计的维度自评或互评，可视化呈现教学能力画像
- AI 角色 → 一个"教学能力教练"角色，通过对话帮老师发现自己的能力维度分布：哪些维度强、哪些维度是盲区
- 工作流 → 输入一位老师的教学记录/自述 → 按你设计的维度框架自动分析 → 输出教学能力画像 + 成长建议
- Skill → "拆解教师教学能力维度"的分析提示词模板，包含你提炼的维度框架和每个维度的判断标准

### 卡 6：带一个人读懂一篇"读不下去"的东西

> **情境**：有一篇东西，学习者知道它很重要，但就是读不下去——可能是一篇文言文、一篇英语长文、一篇学术论文、一段复杂的证明推导、一本书的某个章节，甚至是一份技术文档。
>
> 读不下去的原因各不相同：可能是生词太多，可能是背景知识不够，可能是逻辑链太长跟不上，也可能就是"看两行就走神"。
>
> **你的任务**：做一个东西，能把任何一篇"读不下去"的材料，变成一个**引导式的阅读体验**——不是帮学习者读完（不是让 AI 给你总结），而是带着 Ta 一步步读进去、读懂。不限学科、不限材料类型。

**背后的认知推动**：阅读不是"看完就算"，是一种需要引导的思维活动。AI 最该做的不是帮你总结一篇文章，而是带着你一步步走进去——让你自己读懂，而不是替你读。

**四个赛道怎么接**：
- HTML → 上传/粘贴一篇材料 → 生成分层引导式阅读页面（拆段、注释、追问、背景补充）
- AI 角色 → 一个"阅读搭档"，陪你一段一段读，读完一段问你"这段在说什么"，卡住了帮你补背景
- 工作流 → 输入材料 → 自动分析难点 → 生成"逐段引导阅读方案"（含预设问题和背景知识补充）
- Skill → "把一篇难文章变成引导式阅读体验"的提示词模板

### 卡 7：从一道错题出发，找到学生真正卡在哪

> **情境**：一个学生做错了一道题。你看了一眼——错了。但"错了"这个信息几乎没用。真正有用的是：Ta 到底在哪一步走偏了？是这个概念**从来没搞懂**，还是**搞懂了但忘了**？是**单独会但放到综合题就乱了**，还是**换个情境就不认识了**？
>
> 这四种情况，修复方式完全不同。但传统的错题分析只能告诉你"这道题考的是XX知识点，你不会"。
>
> **你的任务**：做一个东西，从**一道错题**出发，帮老师或学生自己精准定位**思维到底断在哪一步、断的是什么类型**，并给出对应的修复方向。不限学科。

**背后的认知推动**：传统错题分析的单位是"知识点"——你不会勾股定理。但真正的分析单位应该是"步骤中的断点"——你在判断直角的那一步断了。同样的知识点，不同的断点，需要的干预完全不同。从"知道答案错了"到"知道思维在哪一步断了"，这是质变。

**四个赛道怎么接**：
- HTML → 输入一道错题和学生的解题过程 → 可视化标注"思维断在哪一步" → 输出修复建议
- AI 角色 → 一个"错题诊断师"，不告诉你正确答案，而是追问你"你当时是怎么想的"，帮你自己发现卡在哪
- 工作流 → 错题 + 学生解题过程 → 自动分析断点类型（概念缺失/遗忘/整合混乱/迁移障碍） → 输出针对性修复方案
- Skill → "从一道错题诊断思维断点"的提示词模板

### 卡 8：给一个"必须学但没人想学"的知识设计一个让人想试的东西

> **情境**：有一个知识点，所有人都知道它很重要，但学习者就是提不起兴趣——可能是英语语法、数学公式推导、化学方程式配平、历史事件年表、编程基础语法……每个学科都有这种"明知重要但就是无聊"的内容。
>
> **你的任务**：选一个你学科里**公认无聊但必须学**的知识点，做一个东西，让学习者看到就想试试——可以是互动游戏、情境体验、角色扮演、闯关挑战、故事化包装，形式不限。目标只有一个：**让人从"不得不学"变成"想试试"**。不限学科。

**背后的认知推动**：没有无聊的知识，只有无聊的呈现方式。"让人想学"不是简单地加积分加排行榜，而是找到这个知识和学习者真实生活之间的连接点，或者把学习过程本身变成一件有趣的事。

**四个赛道怎么接**：
- HTML → 选一个枯燥知识点 → 做成一个有故事/有互动/有挑战的学习页面
- AI 角色 → 一个"学习体验设计师"，帮你把一个知识点包装成学习者在意的问题或有趣的情境
- 工作流 → 输入知识点 + 学习者画像 → 输出情境化学习方案（故事线 + 互动设计 + 检测点）
- Skill → "把枯燥知识变成让人想试的体验"提示词模板

### 卡 9：为你的学生设计一个 AI 学习搭档

> **情境**：你班上有学生课后想复习和练习，但你不可能 24 小时在线辅导每一个人。你希望有一个 AI 能"代替你"，在学生课后练习的时候，按照**你的教学理念和引导方式**来陪学生——不是直接给答案，而是像你一样提问、引导、纠正。
>
> **你的任务**：为你的学生设计一个**课后 AI 学习搭档**——它按照你的教学逻辑来工作，学生打开就能用。你来决定它怎么引导、怎么追问、什么时候给提示、什么时候让学生自己想。

**背后的认知推动**：AI 教学的终极形态不是"AI 替代老师"，而是"老师用 AI 为学生设计学习系统"。老师把自己的教学逻辑和引导方式封装进 AI，AI 就变成了你的教学分身——24 小时陪着每一个学生，但背后是你的专业判断。

**四个赛道怎么接**：
- HTML → 一个学生端的练习/学习工具，内嵌了你的教学引导逻辑
- AI 角色 → 一个按你的风格工作的"AI 助教"角色，学生课后直接跟它对话练习
- 工作流 → 学生提出问题/提交练习 → 按你设定的引导流程逐步引导 → 输出学习记录给你
- Skill → "按我的教学逻辑引导学生"的教师定制化 Skill 模板

### 卡 10：给学生建一份"活的"学习画像

> **情境**：你带了一个班三年，对每个学生的了解比家长还深——谁擅长什么、谁卡在哪、谁需要鼓励才能动起来、谁一被当众点名就关机。但这些了解全存在你脑子里。下一个接班的老师第一天走进教室，面对四十个陌生的面孔，从零开始。你三年的理解，就这么消失了。
>
> 而且，你对学生的理解只是你的视角——学生自己可能有完全不同的感受。**这个落差本身，才是最有价值的信号。**
>
> **你的任务**：做一个东西，能帮老师**给学生建起一份"活的"学习画像**——不只是成绩和分数，而是学习风格、认知卡点、有效的引导方式、情绪状态、成长轨迹。如果能同时听到老师和学生两边的声音，让两个视角的差距变得可见，那就更好了。

**背后的认知推动**：教育里最有价值、也最容易消失的东西，就是老师对学生的理解。成绩只是冰山一角——这个学生是怎么学的、什么情况下状态好、什么方式对 Ta 有效——这些信息比分数重要一百倍，但从来没有被系统化记录过。AI 能做的不是替代这种理解，是给它一个不会消失的载体。

**四个赛道怎么接**：
- HTML → 一个学生画像工具，老师输入日常观察，自动整合成结构化的、持续更新的学生档案
- AI 角色 → 一个"学生观察搭档"，老师跟它聊某个学生的情况，它帮你整理、追问、补全，逐渐拼出完整画像
- 工作流 → 老师输入观察记录 + 学生输入自我反馈 → 自动生成/更新画像 → 标注两个视角的差距
- Skill → "从日常观察中构建学生学习画像"的提示词模板

## 抽卡机制建议

### 选 5 还是选 10？

- 如果每场 5 组：从 10 张里随机抽 5 张，每组抽 1 张
- 如果想控制难度：提前从 10 张里选 5 张作为本场卡池，再让每组抽
- 后续办第二场的时候可以换另外 5 张，保持新鲜感

### 抽卡流程

1. 开场介绍规则和四个赛道（5 分钟）
2. 各组确认赛道
3. 每组派一人上来抽卡（线上可以做一个翻牌页面）
4. 抽完后全场公布每组的情境卡
5. 进入 100 分钟创作

### 提交时的要求

每组提交作品卡片时，除了原来的内容，加一项：

> **你抽到了什么卡？你的作品是怎么回应这个情境的？**

这一条非常关键——它让评价有了锚点，大家不是在比"谁做得精致"，而是在比"谁把这个真实问题解决得更好"。
