**赛道**：AI 角色
**主题**：一切皆可学
**核心形态**：希沃一体机/电脑轻量化桌面宠物

## 一、项目定位
一只扎根教室的**软萌离线AI桌宠**小咕噜——让想法在脑袋里咕噜咕噜冒出来。无需手动操作、无需点击屏幕，通过**语音自动识别学生姓名**触发互动与记录，全程守护孩子好奇心；数据自动同步飞书多维表格，最终通过 Notebook LM 生成可视化学习报告，真正实现「从好奇到学习，从个体到全班」的教育闭环。

## 二、产品形态
- 运行设备：教室希沃一体机 / Windows 教学白板
- 核心框架：**PySide6 桌面宠物引擎**
- 交互表现：无边框透明悬浮、置顶不抢焦点、可爱动画反馈、可拖拽移动、上课一键隐身
- 核心特色：**纯无感运行**，老师正常讲课即可完成全流程数据采集

## 三、全自动交互流程（零操作·姓名智能触发）
```
老师课堂发言（语音）
→ Vosk 本地离线实时语音转文字
→ AI 自动匹配班级花名册，精准识别学生姓名
→ 姓名触发：桌宠播放动画 + 自动记录课堂关注行为
→ OpenClaw 无缝同步数据至飞书多维表格
→ 周期汇总 → Notebook LM 生成可视化学习周报/手抄报
```

## 四、核心设计理念
1. **全自动无感记录**：老师无需任何操作，正常讲课即可触发，不占用教学时间
2. **姓名即交互入口**：精准识别学生姓名，让每一位孩子都被看见、被记录
3. **引导式好奇心教育**：不提供标准答案，用反问与探索式对话激发思考
4. **数据闭环可视化**：课堂语音→记录→同步→展示，全链路自动化

## 五、使用场景
- 适用对象：小学生 & 任课教师
- 使用环境：教室课堂、课间、课后服务
- 核心模式：**全自动运行 + 可视化输出**，开箱即用

## 六、已实现完整技术细节（核心交付版）
### 1. 桌面宠物层：PySide6
- 实现透明无边框悬浮窗口，适配希沃白板分辨率
- 支持动画状态：待机、聆听、姓名触发互动、记录中
- 窗口特性：不抢占焦点、不遮挡课件、鼠标可拖动、支持一键最小化
- 轻量化运行：内存占用＜50MB，低配教学设备流畅运行

### 2. 语音识别层：Vosk 离线语音转文字（已完成集成）
- **纯本地离线运行**，无需联网、无隐私风险，教室无网环境可用
- 实时流式转写，低延迟、高抗噪，适配教室环境音
- 精准识别中文课堂口语，优化学生姓名、课堂用语识别率
- 与桌宠内核深度绑定，转写结果实时推送至姓名匹配模块

### 3. 核心触发引擎：学生姓名自动匹配（无需手动操作）
- 支持一键导入 Excel 班级学生花名册
- 语音转文字后**全自动关键词匹配**，检测到学生姓名立即触发
- 自动分类记录行为：表扬、课堂发言、提问、小组评价
- 内置同名/同音优化算法，避免课堂识别错误

### 4. 数据同步层：OpenClaw → 飞书多维表格
- 通过 **OpenClaw 自动化接口** 实现数据无感打通
- 实时同步字段：学生姓名、触发时间、行为类型、课堂内容
- 教师可在飞书多维表格实时查看：本节课关注名单、互动次数、学生覆盖度
- 支持多班级、多学科数据分类管理，权限安全可控

### 5. 可视化生成层：Notebook LM
- 自动拉取飞书多维表格周期数据
- 生成内容：班级好奇心周报、学生关注分布图、探究问题手抄报、知识图谱
- 风格适配教学场景，支持直接打印张贴教室墙面
- 优质问题自动提炼，可直接转化为 PBL 项目化学习素材

## 七、教师端全自动工作流
1. **课前**：导入一次学生花名册，启动桌宠
2. **课中**：正常教学，语音自动识别姓名→触发记录→同步飞书
3. **课后**：无需整理数据，系统自动汇总
4. **周末**：Notebook LM 一键生成班级可视化学习报告
5. **应用**：打印展示、生成探究课程、关注沉默学生
