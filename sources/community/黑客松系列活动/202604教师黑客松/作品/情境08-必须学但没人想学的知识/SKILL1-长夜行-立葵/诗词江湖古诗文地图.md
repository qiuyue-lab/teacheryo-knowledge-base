# 诗词江湖·古诗文地图

## 描述
一个融合水墨山水风格与游戏化学习的中小学古诗文学习应用，包含60首初高中必背古诗词，通过填空挑战和默写挑战帮助用户掌握古诗文。

## 使用方法

### 打开应用
在浏览器中打开 `诗词江湖_古文游历录.html` 文件即可运行。

### 主要功能

#### 1. 诗词地图（水墨山水探索模式）
- **迷雾探索**：诗词节点初始被迷雾覆盖，完成相邻诗词后可解锁周围节点
- **流动光效**：已通关的诗词之间显示流光动画路径
- **水墨背景**：宣纸纹理+远山淡影+飘动云雾的国风视觉效果
- **节点标识**：
  - 绿色✓ = 已探索
  - 红色发光 = 可探索
  - 灰色模糊 = 迷雾中（需解锁）

#### 2. 诗词列表
- 按学段（初中/高中）和体裁（诗/词/文）筛选
- 卡片式展示诗词标题、作者、体裁
- 显示完成状态

#### 3. 诗人名录
- 展示35位诗人头像和代表作数量
- 点击可查看诗人详细介绍和背景

#### 4. 我的成就
- **分级体系**：童生 → 秀才 → 举人 → 探花 → 榜眼 → 状元
- 完成特定数量的诗词可解锁对应成就徽章

### 学习流程

#### 阶段一：填空挑战
1. 点击地图或列表中的诗词节点
2. 在诗句空缺处选择正确的字词（5选1）
3. 依次完成所有空缺即可进入下一阶段

#### 阶段二：默写挑战
1. 根据题目提示（中高考默写格式）
2. 输入指定的诗句（一句或两句）
3. 系统会显示需要填写的空缺数量（________）
4. 提交后正确即可完成该诗词

### 数据说明
- **诗词数量**：60首（初中+高中必背）
- **诗人数量**：35位
- **体裁分布**：诗、词、文
- **难度分级**：初中、高中

## 技术特点
- 单文件React应用，无需服务器
- 本地存储学习进度（浏览器localStorage）
- 响应式设计，支持移动端和桌面端
- SVG动画实现流动光效和迷雾效果
