# 教师AI黑客松 · 情境卡锦囊版

> 当你完全卡住没有思路时，点开锦囊。
> 锦囊按你选的赛道给出一个具体的切入方向——不是答案，是一个起点。

---

## 卡 1：一个知识点，三种学生

**🔧 HTML 赛道**：做一个输入知识点后能生成"三层任务"的页面。基础层是填空/选择，巩固层是解释为什么，挑战层是用这个知识点出一道题考别人。学生打开后自己选择从哪一层开始。关键：让学生自己选难度，不是老师分组。

**🤖 AI 角色赛道**：设计一个会"动态判断学生水平"的导学助手——它先问一个试探题，根据回答判断学生在哪个层次，然后切换对应的引导方式。对已经会的学生追问更深，对卡住的学生换一个角度解释。

**⚙️ 工作流赛道**：输入一个知识点 → 第一步自动生成三层任务单（挑战/巩固/补基础）→ 第二步为每层生成对应的引导语和追问策略 → 输出一份"分层课堂活动方案"。

**📋 Skill 赛道**：提炼一套"同一知识点三种难度设计"的提示词模板。模板要能接受任意学科的任意知识点，输出三个层次各自的任务描述 + 适合该层次的引导语风格。

## 卡 2：AI 时代的作业设计

**🔧 HTML 赛道**：做一个"思考过程提交"工具——学生不只是提交最终答案，而是提交"我跟 AI 的对话记录 + 我在哪一步追问了 AI + 我觉得 AI 哪里说得不够好"。让思考过程变得可见、可评价。

**🤖 AI 角色赛道**：设计一个"苏格拉底式作业助手"——学生来问问题，它不直接给答案，只问"你目前想到了什么？""你觉得卡在哪里？"直到学生自己说出答案。可以加一个规则：如果学生说"你直接告诉我答案"，它会说"不行，但我可以再给你一个提示"。

**⚙️ 工作流赛道**：学生提交作业 → 工作流检测作业里是否有思考痕迹（追问、质疑、修改过程）→ 如果只有结果没有过程，自动生成一组追问发回给学生，要求 Ta 补充思考过程。

**📋 Skill 赛道**：设计一套"防糊弄作业"提示词模板——老师输入作业类型和学科，模板帮你把作业改造成"必须展示思考过程"的版本，并附上评价标准（怎么判断思考是真实的）。

## 卡 3：出一道好题

**🔧 HTML 赛道**：做一个"命题工具"——输入知识点 + 你想考察的能力（理解/迁移/分析/评价）→ 生成一道考察对应能力的题目 + 评分标准 + 预测学生的三种常见错误。重点：不只是出题，是出题 + 告诉你为什么这道题是"好题"。

**🤖 AI 角色赛道**：设计一个"命题顾问"角色——老师说"我要考这个知识点"，它不直接出题，而是先追问："你想区分的是哪种能力？""你希望学生没法靠记忆得分，具体是指什么？"通过几轮对话帮老师想清楚考察意图，最后再出题。

**⚙️ 工作流赛道**：输入知识点 → 第一步分析该知识点的常见误解和思维卡点 → 第二步围绕一个卡点设计"陷阱情境" → 第三步生成题目 + 评分标准 + 常见错误分析 → 输出完整命题方案。

**📋 Skill 赛道**：提炼一套"从考察能力出发的命题"提示词模板。模板包含：如何从知识点推导出可考察的能力点、如何设计让学生无法靠记忆得分的情境、如何写出能区分"真懂"和"背出来"的评分标准。

## 卡 4：一切皆可学

**🔧 HTML 赛道**：做一个"好奇心入口"页面——用户输入任何问题或上传一张照片，页面先给一个"意想不到的角度"（让人更好奇），然后提供三条探索路径让用户自己选：想了解背景故事？想看底层原理？还是想找到和自己生活的连接？

**🤖 AI 角色赛道**：设计一个"万能学习搭子"角色——用户说"我好奇X"，它不直接科普，而是先问一个问题让用户思考，然后根据用户的回答决定从哪个深度切入。核心：从好奇心出发，让用户自己参与探索，而不是被动接受信息。

**⚙️ 工作流赛道**：输入任意问题/照片/概念 → 第一步判断领域和用户可能的背景知识水平 → 第二步生成"探索地图"（从入门到深入的几个关键问题） → 第三步按用户选择的路径逐步展开，每一步都以问题结尾，引导用户继续探索。

**📋 Skill 赛道**：设计一套"把任何好奇心变成一段学习"的引导提示词——核心逻辑是：先用一个出乎意料的事实勾住好奇心 → 再提供分叉路径让学习者自选方向 → 每个回答结尾都留一个新问题，让学习者想继续。

## 卡 5：名师是怎么炼成的

**🔧 HTML 赛道**：做一个"教学能力拆解"自评工具——你先定义出几个关键维度（比如：学科理解深度、提问引导能力、课堂节奏把控、学生状态感知……），老师在每个维度上自评并写出具体案例，页面自动生成一份可视化的"教学能力画像"，一眼看出强项和盲区。

**🤖 AI 角色赛道**：设计一个"教学能力教练"角色——它沿着你设计的维度框架，通过对话帮老师拆解自己的教学能力。比如问"你最近一次让学生'突然开窍'是什么时候？你做了什么？"从具体案例里判断这个老师在哪些维度强、哪些维度还有成长空间。

**⚙️ 工作流赛道**：先设计你的维度框架 → 输入一位老师的教学记录或自述 → 按维度自动分析（哪些维度有证据支持、哪些维度缺乏信息）→ 输出教学能力画像 + 每个薄弱维度的具体成长建议。

**📋 Skill 赛道**：提炼一套"拆解教师教学能力"的分析提示词模板——核心是你设计的维度框架：包含哪些维度、每个维度怎么判断（从哪些行为/案例中看出来）、怎么从自评或观察中提取证据。

## 卡 6：带一个人读懂一篇"读不下去"的东西

**🔧 HTML 赛道**：做一个"引导式阅读"页面——用户粘贴一篇材料，页面自动把它切成小段，每段后面跟一个理解确认问题（"这段在说什么？""作者为什么要提这个？"），遇到难词/难句自动提供注释，遇到需要背景知识的地方自动补充。

**🤖 AI 角色赛道**：设计一个"阅读搭档"角色——用户贴入一篇材料后，它陪用户一段一段读：先让用户读一段，然后问"这段在说什么？"用户说不清就帮 Ta 拆解，说得出来就继续下一段。遇到背景知识缺口的地方，主动插入补充，而不是让用户自己去搜。

**⚙️ 工作流赛道**：输入一篇材料 → 第一步分析难点分布（生词/背景知识缺口/逻辑跳跃）→ 第二步按难点位置切分段落 → 第三步为每个切分点生成预设问题和背景补充 → 输出完整的"引导式阅读方案"。

**📋 Skill 赛道**：提炼一套"把难文章变成引导式阅读体验"的提示词模板——包含：如何拆分段落、如何设计每段的理解确认问题、如何识别并补充背景知识缺口、如何在不剧透的情况下帮用户读懂。

## 卡 7：从一道错题出发，找到学生真正卡在哪

**🔧 HTML 赛道**：做一个"错题诊断"工具——输入错题和学生的解题过程，工具可视化展示"思维路径"，标注出在哪一步出现了分叉，判断断点类型（概念缺失/遗忘/整合混乱/迁移障碍），并给出对应的修复建议。

**🤖 AI 角色赛道**：设计一个"错题诊断师"角色——不告诉学生正确答案，而是追问"你当时是怎么想的？""你觉得哪一步有点不确定？"通过几轮对话帮学生自己找到思维的分叉点，最后告诉 Ta 卡的是哪种类型的断点，应该怎么修复。

**⚙️ 工作流赛道**：输入错题 + 学生解题过程 → 第一步还原学生的思维路径 → 第二步对比正确思维路径找到分叉点 → 第三步判断断点类型（四种）→ 第四步根据断点类型输出针对性修复方案（对应练习/重新讲解/迁移练习）。

**📋 Skill 赛道**：提炼一套"从错题诊断思维断点"的提示词模板——包含：如何追问还原学生思维路径、如何判断四种断点类型、如何为每种断点类型生成对应的修复建议。

## 卡 8：给一个"必须学但没人想学"的知识设计一个让人想试的东西

**🔧 HTML 赛道**：做一个有故事线的互动学习页面——把知识点放进一个让人在意的真实情境里（比如"你是一名消防员，需要计算灭火剂的用量"），学习者通过解决情境中的问题来学会知识，而不是直接背定义做练习题。

**🤖 AI 角色赛道**：设计一个"学习动机设计师"角色——老师告诉它一个枯燥的知识点，它帮老师找到"这个知识在真实生活中什么时候突然变得有用/有趣"，然后帮老师把这个连接点变成一个有吸引力的学习入口。

**⚙️ 工作流赛道**：输入知识点 + 目标学习者画像 → 第一步找出这个知识和学习者真实生活的3个连接点 → 第二步选最有冲击力的那个 → 第三步围绕这个连接点设计情境 → 输出"情境化学习活动方案"（情境描述 + 学习任务 + 检测点）。

**📋 Skill 赛道**：提炼一套"把枯燥知识变成让人想试的体验"提示词模板——核心逻辑：先找真实连接点 → 用连接点设计情境 → 把知识学习嵌进情境中的任务 → 用完成任务的成就感代替"我学了一个知识点"的感觉。

## 卡 9：为你的学生设计一个 AI 学习搭档

**🔧 HTML 赛道**：做一个学生端的练习工具——内嵌老师设计的引导逻辑：学生提交答案或问题后，不直接显示对错，而是先问"你是怎么想到这一步的？"然后根据回答决定给提示还是追问。老师提前设定"什么情况下给提示、给什么提示"。

**🤖 AI 角色赛道**：设计一个"按老师风格工作的 AI 助教"——先把老师的教学理念和引导习惯提炼出来（爱用什么比喻、什么时候会直接告诉答案、什么情况下会反问学生），然后把这些封装进角色，让 AI 助教用老师的风格陪学生练习。

**⚙️ 工作流赛道**：老师设定引导规则（什么时候介入、介入时说什么）→ 学生提交问题/练习 → 工作流按老师的规则判断当前情况 → 选择对应的引导策略 → 输出引导内容 + 记录学习过程反馈给老师。

**📋 Skill 赛道**：提炼一套"按我的教学逻辑引导学生"的教师定制化提示词模板——包含：如何把老师的教学风格和引导习惯结构化、如何设定"什么情况下给提示"的规则、如何让 AI 既能帮学生又不会直接代替学生思考。

## 卡 10：给学生建一份"活的"学习画像

**🔧 HTML 赛道**：做一个学生画像管理页面——老师可以随时输入对某个学生的观察（"今天张三在XX这里卡住了""他用XX方式解释后一下子明白了"），系统自动整合成结构化的画像，并标注最近的变化趋势。如果能加上学生自己填写的反馈，显示两个视角的差距更好。

**🤖 AI 角色赛道**：设计一个"学生观察搭档"角色——老师跟它随口聊某个学生（"这周李四状态很怪，不知道为什么"），它帮老师追问细节、整理成结构化的画像片段、并和之前的记录比对，发现值得注意的变化。

**⚙️ 工作流赛道**：老师输入观察记录 → 第一步提取关键信息（学习状态/情绪信号/认知卡点/有效触发方式）→ 第二步与已有画像合并更新 → 第三步如有学生自我反馈，对比两个视角的差距 → 输出更新后的画像 + 下次沟通的建议切入点。

**📋 Skill 赛道**：提炼一套"从日常观察构建学生学习画像"的提示词模板——包含：如何从零散的观察中提取有价值的信息、画像的结构维度（认知地图/卡点记录/有效触发方式/情绪信号）、如何识别老师视角和学生视角的差距。
