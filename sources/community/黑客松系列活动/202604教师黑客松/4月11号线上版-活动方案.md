# 教师AI黑客松 · 线上版
**日期**：2026年4月11日（周六）14:00-17:20  
**时长**：约3.5小时  
**形式**：线上（腾讯会议主会场 + 分会场）  
**团队**：2人搭档制  
**工具**：自带，不统一指定平台

---

## 活动流程

```
14:00 ─── 主会场（20分钟）
          开场说明 + 赛道介绍 + 搭档确认 + 进入分会场

14:20 ─── 分会场创作（100分钟）
          各搭档在自己赛道的分会场工作
          主持人在各赛道小群实时答疑
          最后10分钟填好作品卡片

16:00 ─── 回主会场，贴卡片（10分钟）
          所有组把作品卡片贴到共享白板

16:10 ─── 自由浏览 + 投票（20分钟）
          所有人自由点开每张卡片去看、去试用
          同时投票：「哪个作品你最想拿走用？」

16:30 ─── 现场演示（40分钟）
          每赛道票数最高的2组上来演示
          共8组，每组5分钟，直接演示作品

17:10 ─── 总结（10分钟）
          主持人收尾，发布所有作品卡片汇总链接

17:20 ─── 结束 ✓
```

## 四条赛道

工具不统一指定，各组用自己熟悉的平台。赛道按产出物类型分，不按难度排序。

---

### 赛道一：HTML工具

**做什么**：让AI帮你做一个能在浏览器里跑的互动工具。你不需要会写代码——你只需要知道你想要一个什么工具，然后用Claude Artifacts / Cursor / 任何AI工具生成。

**产出**：一个可以直接打开、能演示核心功能的HTML页面

**展示方式**：屏幕共享，直接操作这个工具给大家看

**选题清单（选一个）**：
1. 单元知识点互动测验 —— 输入考点，自动生成带选项和解析的小测
2. 作文结构反馈表单 —— 学生粘贴作文，AI给出结构化批改意见
3. 词汇/概念记忆卡片 —— 输入词表，生成带例句和图示的记忆卡
4. 课前热身题生成器 —— 输入上节课内容，自动出3道热身题
5. 自选 —— 只要能在浏览器里跑就行

**脚手架**：

| 时间 | 做什么 |
|---|---|
| 前10分钟 | 两个人讨论：我们要做什么工具？用户是谁？核心操作是什么？输出是什么？用一句话描述出来 |
| 10-30分钟 | 把这句话发给AI，让它生成HTML。推荐指令：「帮我做一个完整的HTML单页工具，功能是[你的描述]，不需要后端，所有逻辑在前端完成」 |
| 30-60分钟 | 用一个真实案例测试。哪里不对→告诉AI→让它修改。反复迭代 |
| 60-80分钟 | 测试最终版本，确认链接能打开 |
| 80-100分钟 | 填作品卡片。想好展示时用哪个真实案例来演示 |

### 赛道二：AI角色

**做什么**：设计一个有明确人格、知识边界和使用场景的AI角色。可以是学生用的辅导助手，也可以是你自己用的教学搭档。平台自选：扣子、GPTs、Claude Project、Dify……

**产出**：一个可以分享链接或直接演示对话的AI角色

**展示方式**：屏幕共享，现场和这个角色对话一轮，让大家看到它怎么工作

**选题清单（选一个）**：
1. 苏格拉底式导师 —— 不直接给答案，用问题引导学生自己想
2. 学科专属答疑助手 —— 只回答某学科问题，乱问时会说"这不是我的范围"
3. 写作反馈者 —— 给学生的写作提供具体的、鼓励性的改进建议
4. 备课搭档 —— 了解你的教学风格和班情，帮你设计一节课的核心活动
5. 自选 —— 明确这个角色是谁、给谁用、解决什么问题

**脚手架**：

| 时间 | 做什么 |
|---|---|
| 前15分钟 | 两个人讨论并回答4个问题：①这个角色叫什么/是谁？②给谁用（老师/学生）？③解决什么具体问题？④有什么边界（什么不做/不回答）？ |
| 15-35分钟 | 写系统提示词。框架：「你是[角色名]，你的职责是[xxx]，你的风格是[xxx]，你不做[xxx]，当用户问你[边界情况]时，你的回应是[xxx]」 |
| 35-70分钟 | 用真实的问题测试3-5轮对话。看它有没有偏离设定。根据测试结果修改提示词 |
| 70-90分钟 | 最终测试，确认链接能分享 |
| 90-100分钟 | 填作品卡片。准备展示时要用的2-3个对话问题 |

### 赛道三：Agent工作流

**做什么**：把一个教学任务拆成几个步骤，用AI自动跑完整个流程。重点不是技术有多复杂，而是这个工作流在真实教学里是不是真的有用。平台自选：扣子工作流、Dify、n8n、Cursor Agent……

**产出**：一个能跑起来、可以演示输入→输出全流程的工作流

**展示方式**：屏幕共享，输入一个真实案例，现场跑一遍，让大家看到输入和输出

**选题清单（选一个）**：
1. 批改汇总工作流 —— 收集学生作业 → AI批改 → 按问题类型汇总反馈
2. 备课自动化 —— 输入本节课目标 → 生成教案草稿+活动设计+练习题
3. 错题分析工作流 —— 输入学生错题 → 分析错误原因 → 生成专项练习
4. 个性化周报生成 —— 根据本周教学内容，自动生成家长版周报
5. 自选 —— 明确输入是什么、输出是什么、中间几步

**脚手架**：

| 时间 | 做什么 |
|---|---|
| 前15分钟 | 两个人先用文字画出工作流：输入是什么？→ 步骤1做什么？→ 步骤2做什么？→ 最终输出是什么？写清楚再动手 |
| 15-50分钟 | 先搭主干：只做最核心的一条链路，把输入→输出跑通。不要一开始就做所有分支 |
| 50-80分钟 | 用一个真实案例测试核心功能。记录哪里出问题，修改。只要主干能跑就算成功 |
| 80-90分钟 | 准备好演示用的真实输入案例 |
| 90-100分钟 | 填作品卡片 |

### 赛道四：提示词Skill

**做什么**：把你在某个教学场景里的专业经验，提炼成一套别人拿走就能用的提示词方法。不是随便写几条提示词，而是一套有结构、有说明、有示例的"可复用技能包"。

**产出**：3-5条有完整使用说明的提示词，整理在一份可分享的文档里

**展示方式**：屏幕共享，现场用其中一条提示词跑一个真实案例，展示输入和输出

**选题清单（选一个）**：
1. 分层作业Skill —— 同一个知识点，自动生成三个难度版本的练习
2. 情境化出题Skill —— 把枯燥习题变成有故事背景的情境题
3. 苏格拉底追问Skill —— 针对任何话题，生成层层深入的讨论问题链
4. 个性化评语Skill —— 根据不同学生特点，生成有温度的针对性评语
5. 自选 —— 明确这个Skill解决什么教学场景的问题

**脚手架**：

| 时间 | 做什么 |
|---|---|
| 前10分钟 | 确定场景：越具体越好。不是「帮我出题」，而是「给八年级英语，出一道考现在完成时的情境填空，难度适中，带详细解析」 |
| 10-30分钟 | 先用最直接的方式让AI做这件事，看看效果。记录：哪里不好？需要AI做哪些调整？ |
| 30-60分钟 | 把刚才的经验提炼成可复用的提示词：哪些部分每次都一样（固定下来）？哪些部分每次不同（设成[变量]）？ |
| 60-85分钟 | 为每条提示词写使用说明：这条Skill解决什么问题？变量怎么填？贴上示例输入+示例输出 |
| 85-100分钟 | 整理成一份干净的文档，填作品卡片 |

## 作品卡片

每组在创作阶段最后10分钟填完，填完后贴到共享白板。

**三个用途**：
1. 填的过程逼着两个人把"我们到底做了什么"想清楚
2. 贴到白板后代替逐一汇报，所有人自由浏览
3. 活动结束后汇总成资源包，所有人都可以带走

**模板**：

```
【赛道】HTML工具 / AI角色 / Agent工作流 / 提示词Skill

【作品名】
起一个让人一眼看懂的名字

【一句话介绍】
这是一个___，帮___解决___的问题

【给谁用？怎么用？】
适合___学科/学段的老师，在___场景下，___操作就能用

【作品链接/演示方式】
链接 / 截图 / 现场共享屏幕
```

---

## 展示流程（16:00-17:20）

### 贴卡片（16:00-16:10）
- 所有搭档回到主会场
- 把填好的作品卡片贴到共享白板

### 自由浏览 + 投票（16:10-16:30）
- 所有人自由点开白板上的卡片，去看、去试用每个作品
- 同时进行投票（腾讯问卷或文档投票）
- 投票题只有一道：**「看完所有作品，你最想拿哪个回去用？（单选）」**

### 现场演示（16:30-17:10）
- 每条赛道票数最高的2组上来演示，共8组
- 每组 **5分钟**，直接演示作品，不解释设计思路
- 格式：「我们做的是___，现在演示一下」→ 直接操作
- 主持人控时，5分钟到立刻切换

### 总结（17:10-17:20）
- 主持人做简短收尾
- 发布所有作品卡片的汇总链接，所有人都可以带走

## 搭档配对机制

**活动前配对好，不现场临时抓。**

报名时收集：
- 姓名 + 学科 + 学段
- AI使用经验（新手 / 有些基础 / 熟练）
- 赛道意向（四选一 / 随便都行）

配对逻辑：
- 同赛道内配对（能真正协作，不是分工做两件事）
- 优先同学段（能理解对方的真实场景）
- 奇数人数时出现一个3人组

## 本次活动的最低目标

**必须达到的**：
- 每对搭档都有一个可以带走的作品（哪怕很粗糙）
- 没有人感到被孤立、一个人在战斗
- 至少有人在浏览卡片时说"这个我真的要拿回去用"

**不追求的**：
- 作品很完美
- 每个赛道都有人参与
- 像正式活动一样隆重
