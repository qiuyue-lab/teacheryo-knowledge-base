## 学科参数包

### 维度表（D）

| 编号 | 维度名称 |
| ---- | -------- |
| D1   | 数学抽象 |

| D3   | 数学建模 |
| D4   | 直观想象 |

> **注**：D5数学运算在课标学业质量描述中始终嵌入在问题解决、函数分析、几何探索等过程中，不单独描述，因此不会作为任何题点的主维度出现，但在多个题点中作为关联维度出现。课标将运算视为工具性能力而非独立考查目标。

### 动词表（V）

| 水平   | 典型动词                                                   |
| ------ | ---------------------------------------------------------- |
| 水平一 | 发现、提出、借鉴、运用、计算、论证、解释、识别、建立、描述 |
| 水平二 | 构建、改进、研究、选择、刻画、比较、辨别、反思             |
| 水平三 | 创造性运用、总结、整体构建、主动学习、拓展、探索           |

### 递进特征表（L）

| 递进维度   | 水平一                               | 水平二                                         | 水平三                                   |
| ---------- | ------------------------------------ | ---------------------------------------------- | ---------------------------------------- |

| 认知深度   | 借鉴已有思路、运用、计算、论证       | 构建思路、分析、改进模型、反思合理性           | 创造性运用、整体构建知识体系、主动拓展   |
| 自主程度   | 借鉴已有的解决问题思路               | 构建解决问题的思路、得到一般方法               | 创造性地运用、主动学习选修课程           |

## 水平一 题点拆分

### 1.R1 问题解决（通用）

**题点 1.R1.1 在熟悉情境中发现提出问题并求解**

> 课标原文："在熟悉的情境即学生有直接生活经历或学习经验的情境中，能发现和提出有意义的数学问题，借鉴已有的解决问题思路，运用数学概念、公式、定理、模型等，进行计算或论证，得到结果，能解释结果的意义"

- 主维度：D3 数学建模
- 关联维度：D5 数学运算、D2 逻辑推理
- 领域：R1 问题解决
- 链式题点（发现提出→借鉴思路→运用工具→计算论证→解释结果）
- 微题点：

| 编码     | 名称               | 操作描述                                                 |
| -------- | ------------------ | -------------------------------------------------------- |
| 1.R1.1.1 | 发现和提出数学问题 | 能够在熟悉的情境中发现和提出有意义的数学问题             |
| 1.R1.1.2 | 运用数学工具计算   | 能够借鉴已有思路，运用数学概念、公式、定理、模型进行计算 |
| 1.R1.1.3 | 运用数学工具论证   | 能够借鉴已有思路，运用数学概念、公式、定理、模型进行论证 |
| 1.R1.1.4 | 解释结果的意义     | 能够解释计算或论证结果的意义                             |

**题点 1.R1.2 探索通性通法**

> 课标原文："具有探索通性通法的意识，能解释解决问题的过程"

- 主维度：D2 逻辑推理
- 领域：R1 问题解决
- 不拆微题点（链式关系——"探索通性通法"是前提，"解释过程"依附于探索结果，无法脱离探索独立出题）
- 应用说明：
  - 具有探索通性通法的意识
  - 能够解释解决问题的过程
