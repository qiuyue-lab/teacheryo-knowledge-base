# 命题能力实施路线图 - 快速参考

**方案**: Analyst增加第4工作模式（命题设计模式）
**核心理念**: 解析↔命题的认知对称性
**目标**: 2-3周实现MVP，命题质量达到70%

---

## 🚀 立即行动：手动验证（今天）

### 目的
零成本验证"解析↔命题"可行性

### 步骤（2-3小时）

1. **选择真题**
   - 找一道高质量真题（选择题）
   - 建议选择结构清晰、干扰项设计好的

2. **深度解析**
   ```
   提示词：
   "请用选择题解析模式深度分析这道题：
   - 考查目标
   - 材料选择逻辑
   - 设问设计思路
   - 干扰项设计逻辑（每个选项为什么这样设计）"
   ```

3. **提取结构**
   - 记录：材料类型、字数
   - 记录：设问方式、考查角度
   - 记录：干扰项类型（时间错位/概念混淆/逻辑冲突/超范围）

4. **逆向命题**
   ```
   提示词：
   "现在请逆向应用刚才的分析：
   - 保持相同的题目结构
   - 保持相同的干扰项类型
   - 将知识点替换为【洋务运动】
   - 生成一道新的选择题"
   ```

5. **自我验证**
   ```
   提示词：
   "请切换回解析模式，分析你刚才生成的这道题，评估：
   - 考查目标是否明确？
   - 材料选择是否合理？
   - 干扰项是否有效？
   - 整体质量如何？"
   ```

### 判定标准

✅ **通过** → 进入开发阶段
- 生成的题目结构完整
- 知识点准确无误
- 干扰项有一定效果
- 自我验证能发现问题

❌ **不通过** → 调整思路
- 生成题目混乱
- 出现知识性错误
- 干扰项完全无效
- 自我验证失灵

## 📅 Week 2：MVP测试（10道选择题）

### 测试计划

**目标**: 验证命题质量，通过率≥70%

**测试题目分布**：
| 知识点 | 数量 | 难度 |
|--------|------|------|
| 古代史 | 4题 | 基础2 + 中等2 |
| 近代史 | 4题 | 基础2 + 中等2 |
| 现代史 | 2题 | 中等1 + 较难1 |

### 每道题的流程

1. **命题**（20分钟）
   - 确定知识点、难度
   - 运行命题设计模式
   - 生成题目

2. **自我验证**（自动）
   - 6项质量检查
   - 生成验证报告

3. **人工评审**（10分钟）
   - 检查知识准确性
   - 评估干扰项有效性
   - 评定可用性等级（A/B/C/D）

4. **记录**
   - 填写质量评估表
   - 记录问题点
   - 提出改进建议

### 每日计划

- Day 1-2：命题5道题，评审记录
- Day 3-4：命题5道题，评审记录
- Day 5：汇总分析，撰写报告

## 📅 Week 3：评估与决策

### 数据汇总

**质量指标**：
- 自我验证通过率：X/10
- 知识准确性：X/10
- 干扰项有效性：X/10
- 人工可用性：A级X道，B级X道，C级X道，D级X道

### 决策矩阵

| 自我验证通过率 | 人工可用性（B级及以上） | 决策 |
|--------------|----------------------|------|
| ≥70% | ≥70% | ✅ **成功**：进入阶段2（主观题） |
| 50-70% | 50-70% | ⚠️ **一般**：优化迭代或降级为改编模式 |
| <50% | <50% | ❌ **失败**：暂停，分析原因 |

### 成功路径：进入阶段2

**扩展主观题能力**（2周）：
- Week 4：开发主观题专项能力
- Week 5：测试5道主观题
- 成功标准：通过率≥60%

### 一般路径：优化或降级

**优化方向**：
- 加强干扰项设计思维
- 增加真题案例学习
- 优化自我验证标准

**降级方案**：
- 改为"参照改编模式"
- 保持真题结构，替换内容
- 降低创新要求

### 失败路径：分析原因

**可能原因**：
- AI能力不足（根本问题）
- 思维模式设计有误（可优化）
- 知识库不够（可扩充）

**后续方案**：
- 如是根本问题 → 暂停或转向
- 如可优化 → 调整后重试
- 如需数据 → 考虑建真题库

## 🎯 关键成功因素

### 1. 自我验证闭环 ⭐

```
命题模式 → 生成题目
    ↓
解析模式 → 分析题目
    ↓
质量评估 → 6项检查
    ↓
通过 → 输出
不通过 → 迭代（最多3轮）
```

**这是最核心的创新**：Analyst既是命题者，又是审核者

### 2. 预期管理

**不追求完美**：
- MVP目标：70分水平（B级）
- 定位：日常教学练习题
- 非目标：高考真题级别（95分）

**分级使用**：
- A级（≥90%）→ 正式考试
- B级（70-90%）→ 课堂练习
- C级（50-70%）→ 初稿素材
- D级（<50%）→ 废弃

### 3. 风险控制

**止损点明确**：
- 通过率<50% → 暂停
- 知识错误>20% → 根本问题
- 3轮迭代无改善 → 调整策略

**退化机制**：
- 从零设计 → 参照改编
- 高要求 → 降低要求
- 通用命题 → 省份风格（暂缓）

## 💡 快速参考

### 核心洞察
> 解析与命题是同一认知能力的双向应用

### 核心优势
- 2-3周 vs 6-8周（独立角色）
- 100%复用现有能力
- 自我验证闭环
- 风险可控

### 核心风险
- 命题质量可能不如解析质量
- 干扰项设计可能流于表面
- 需人工审核后使用

### 核心成功标准（MVP）
- ✅ 自我验证通过率≥70%
- ✅ 知识准确性100%
- ✅ 干扰项有效性≥60%
- ✅ 可用于日常教学
