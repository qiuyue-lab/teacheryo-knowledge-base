  （基于官方解析，提炼学生解题的思维步骤）

  2.2 关键句提炼的标准格式

  每个关键句必须包含：

  **关键句X**："[原文]"

  **四元分析**：

- **WHAT（做什么）**："[提取的能力点]" → ✅ 独立能力点
- **HOW（怎么做）**：[方法要求] → ❌ 方法要求，融入WHAT
- **WITH WHAT（用什么）**："[史料/对象]" → 史料支撑/对象
- **TO WHAT EXTENT（到什么程度）**："[程度词]" → 程度要求，融入WHAT

  **数据库匹配**：

- 查询关键词：[关键词列表]
- ⚠️ 初步判断：[判断说明]
- 可能匹配：题点X.X [名称]
  - 微题点X.X.X [名称]
- **暂时标注**：[编码或"待数据库核查"]

  2.3 四元区分的判断标准
  ┌────────────────┬────────────────────────────────┬───────────────────────┐
  │      元素      │            判断标准            │       标注方式        │
  ├────────────────┼────────────────────────────────┼───────────────────────┤
  │ WHAT           │ 能独立成为能力点的动作         │ ✅ 独立能力点         │
  ├────────────────┼────────────────────────────────┼───────────────────────┤
  │ HOW            │ 完成WHAT的方法/方式            │ ❌ 方法要求，融入WHAT │
  ├────────────────┼────────────────────────────────┼───────────────────────┤
  │ WITH WHAT      │ 史料支撑/前置知识/对象         │ 不标注为独立能力点    │
  ├────────────────┼────────────────────────────────┼───────────────────────┤
  │ TO WHAT EXTENT │ 程度副词（准确、核心、特定等） │ 程度要求，融入WHAT    │
  └────────────────┴────────────────────────────────┴───────────────────────┘
  关键原则：只有WHAT才能标注为独立能力点！

  6.2 融入要素说明（重要）

  **⚠️重要说明**：
  本表"方法/知识/理论/程度融入"列标注融入该能力点的方法要求、知识支撑、理论工具和程度要求。这些融入要素不是独立能

  八、关键原则总结

  8.1 实事求是原则

  ✅ 只标注官方解析中明确体现的能力点
  ✅ 不凭印象使用编码
  ✅ 数据库没有的编码明确标注为"数据库缺失"
  ✅ 绝不削足适履

  8.2 四元区分法原则

  ✅ 严格区分WHAT、HOW、WITH WHAT、TO WHAT EXTENT
  ✅ 只有WHAT才标注为独立能力点
  ✅ HOW和TO WHAT EXTENT融入WHAT的描述中
  ✅ WITH WHAT不标注为独立能力点

  8.3 数据库验证原则

  ✅ 所有编码都必须在数据库v1.1中查询确认
  ✅ 必须标注数据库行号（v1.1第XXX行）
  ✅ 数据库无对应的能力点标注为"数据库缺失"
  ✅ 不创造新的编码

  8.4 堵点分析原则

  ✅ 能力点≥3个必须完成D.4.1-D.4.7
  ✅ D.4.3干扰选项断点映射表必须输出
  ✅ D.4.4三条件验证表必须输出
  ✅ QT匹配度<90%不能强行使用（红线机制）
  ✅ 新发现必须标注"待验证"状态
