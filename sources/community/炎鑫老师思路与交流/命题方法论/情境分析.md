## 1. 情境分析的意义

### 1.1 为什么分析情境？

情境是工作流的"触发条件"——它决定：
- 学生需要调用哪些认知操作
- 学生需要处理什么类型的对象
- 学生可以自主选择还是执行给定任务

**核心假设**：情境复杂度是学业质量水平区分的首要指标。

---

### 1.2 情境分析的目标

1. **提取**：从 60 个题点中提取完整的情境描述
2. **分解**：将情境描述分解为可测量的要素
3. **量化**：给情境复杂度打分，分析水平分布
4. **匹配**：分析情境与动词、宾语的匹配模式
5. **应用**：为命题设计、学业测量、教学诊断提供依据

## 3. 情境要素编码体系

### 3.1 4 个核心要素

每个情境描述可以分解为**4 个核心要素**：

| 要素代码 | 要素名称 | 定义 | 取值范围 |
|---------|---------|------|---------|
| E1 | 信息源数量 | 提供给学生的信息数量 | 单则/多则/多则多类型/多则多来源多观点/自主 |
| E2 | 信息源类型 | 信息的呈现形式 | 史料/史事/史料→史事/史料 + 问题/问题/价值 |
| E3 | 对象复杂度 | 处理对象的复杂程度 | 具体/特定/一般/复杂/复杂 + 多元 |
| E4 | 框架给定度 | 分析框架的给定程度 | 完全给定/基本给定/部分给定/部分自主/完全自主 |

---

### 3.2 要素评分标准

| 分值 | E1 数量 | E2 类型 | E3 复杂度 | E4 框架 |
|-----|--------|--------|---------|--------|
| 1 分 | 单则 | 史料 | 具体 | 完全给定 |
| 2 分 | 多则 | 史事 | 特定 | 基本给定 |
| 3 分 | 多则多类型 | 史料→史事 | 一般 | 部分给定 |
| 4 分 | 多则多来源多观点 | 史料 + 问题 | 复杂 | 部分自主 |
| 5 分 | 自主 | 问题/价值 | 复杂 + 多元 | 完全自主 |

## 5. 情境复杂度量化

### 5.1 情境复杂度公式

```
情境复杂度 = (E1 数量分 + E2 类型分 + E3 复杂度分 + E4 框架分) / 4
```

---

### 5.2 各水平的情境复杂度

| 水平 | 平均复杂度 | 增幅 | 关键跃迁 |
|-----|-----------|------|---------|
| 水平 1 | 1.1 | - | 基准 |
| 水平 2 | 2.25 | +105% | 单则→多则 |
| 水平 3 | 2.9 | +29% | 多则→多类型 |
| 水平 4 | 4.2 | +45% | 给定→自主 |

**发现**：
- 水平 1→2 增幅最大（+105%）——单则到多则是最大的认知负荷跃迁
- 水平 4 出现"质变"（框架自主选择）——从执行到设计的跃迁

## 6. 情境与动词 - 宾语的匹配模式

### 6.1 情境类型决定动词选择范围

| 情境类型 | 典型动词 | 典型宾语 |
|---------|---------|---------|
| 单则 + 具体 + 给定 | 判断、说明、提炼、举出 | 时间、空间、类型、事件、人物 |
| 多则 + 一般 + 给定 | 综合判断、辨别、明了、说明 | 特征、关联、联系、各自价值 |
| 多则多类型 + 复杂 + 给定 | 综合判断、辨识、整理、概括、评析 | 变化、信息、证据、规律 |
| 自主 + 复杂 + 自主 | 比较、分析、互证、辨析、选择、独立探究 | 意图、真实性、框架、尺度、内涵 |

**发现**：情境类型限制动词选择范围
- 单则情境→单动词（判断、说明）
- 多则情境→综合动词（综合判断、综合整理）
- 自主情境→元认知动词（选择、独立探究）

---

### 6.2 情境类型决定宾语抽象度

| 情境类型 | 宾语抽象度范围 | 示例 |
|---------|--------------|------|
| 单则 + 具体 + 给定 | 1-2 分 | 时间、空间、类型、事件 |
| 多则 + 一般 + 给定 | 2-3 分 | 特征、关联、联系、各自价值 |
| 多则多类型 + 复杂 + 给定 | 2-4 分 | 变化、信息、证据、规律 |
| 自主 + 复杂 + 自主 | 3-5 分 | 意图、框架、尺度、内涵、自信 |

**发现**：情境复杂度与宾语抽象度正相关
- 相关系数：约 0.85（强相关）
- 情境越复杂，宾语抽象度越高

---

### 6.3 情境 - 动词 - 宾语匹配度

```
匹配度 = 1 - |情境复杂度 - (动词复杂度 + 宾语抽象度)/2 |

匹配度接近 1：情境 - 动词 - 宾语匹配良好
匹配度接近 0：情境 - 动词 - 宾语不匹配
```

**应用**：
- 命题设计：确保匹配度>0.7
- 难度控制：通过调整情境复杂度控制整体难度

## 7. 核心发现

### 发现 1：情境复杂度是水平区分的首要指标

```
水平 1 情境：单则 + 具体 + 给定（复杂度 1.1）
水平 2 情境：多则 + 一般 + 给定（复杂度 2.25）
水平 3 情境：多则多类型 + 复杂 + 给定（复杂度 2.9）
水平 4 情境：自主 + 复杂 + 自主（复杂度 4.2）
```

**应用**：
- 命题设计：通过控制情境复杂度控制难度
- 学业测量：通过情境类型判断水平
- 教学诊断：通过情境理解程度识别堵点

---

### 发现 2：框架给定度在水平 4 出现"质变"

```
水平 1-3：完全给定框架（86-100%）
水平 4：自主选择框架（100%）

这是水平 3→4 的本质差异
```

**应用**：
- 水平 4 命题必须设计"自主选择框架"的情境
- 水平 3 及以下不需要自主选择

---

### 发现 3：情境要素之间存在"协同变化"

```
E1 数量增加 → E3 复杂度增加 → E4 框架自主
E2 类型转化 → 宾语抽象度增加 → 动词选择变化

不是单一要素变化，而是要素协同变化
```

---

### 发现 4：情境是工作流的"触发条件"

```
情境类型 → 触发特定动词 → 选择特定宾语 → 形成工作流

示例：
  "对于给定的具体史事及相关史料"
    → 触发：判断、说明、提炼
    → 宾语：时间、空间、事件
    → 工作流：提炼→判断→说明

  "对不同来源、不同观点的史料"
    → 触发：比较、分析、互证、辨析
    → 宾语：史料、意图、真实性
    → 工作流：比较→分析→评析→互证
```

## 8. 应用价值

### 8.1 命题设计

**传统做法**：
"这道题要考判断类簇"

**新视角**：
"设计一个情境，让认知操作自然展开到某个深度"

**设计参数**：
| 参数 | 水平 1-2 | 水平 3 | 水平 4 |
|-----|---------|-------|-------|
| E1 数量 | 单则/多则 | 多则多类型 | 多则多来源多观点/自主 |
| E2 类型 | 史料/史事 | 史料 + 问题 | 问题/价值 |
| E3 复杂度 | 具体/一般 | 复杂 | 复杂 + 多元 |
| E4 框架 | 完全给定 | 完全给定/部分给定 | 自主选择 |

---

### 8.2 学业测量

**传统做法**：
"这道题是水平 3 题"

**新视角**：
"这道题在情境四维度上的参数组合是什么"

**测量维度**：
- E1 数量：单则/多则/多则多类型/自主
- E2 类型：史料/史事/问题/价值
- E3 复杂度：具体/一般/复杂
- E4 框架：给定/自主

---

### 8.3 教学诊断

**传统做法**：
"学生判断类簇掌握不好"

**新视角**：
"学生在哪个情境要素上出现阻塞"

**诊断维度**：
- E1 理解：能否处理多则/多类型信息
- E2 理解：能否识别史料→史事→问题的转化
- E3 理解：能否处理复杂对象
- E4 理解：能否自主选择框架

---

### 8.4 备考训练

**传统做法**：
"多做题，熟能生巧"

**新视角**：
"逐步增加情境复杂度"

**训练序列**：
```
阶段 1：单则 + 具体 + 给定（水平 1）
阶段 2：多则 + 一般 + 给定（水平 2）
阶段 3：多则多类型 + 复杂 + 给定（水平 3）
阶段 4：自主 + 复杂 + 自主（水平 4）
```

## 结语

### 情境分析的核心洞察

**情境的本质**：
> 不是题目的"背景信息"，而是工作流的触发条件

**情境复杂度的本质**：
> 不是信息量的简单增加，而是认知操作模式的质变

**框架给定度的本质**：
> 不是任务要求的差异，而是从"执行"到"设计"的跃迁
