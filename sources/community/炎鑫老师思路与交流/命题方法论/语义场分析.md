## 1. 语义场分析的意义

### 1.1 为什么分析语义场？

语义场是"概念的意义网络"——它揭示：
- 学业质量涉及哪些核心概念
- 这些概念如何组织成网络
- 不同水平需要激活哪些概念网络

**核心假设**：语义场数量和协同模式是学业质量水平区分的重要指标。

---

### 1.2 语义场分析的目标

1. **提取**：从 60 个题点中提取所有名词（概念）
2. **分类**：将概念归类到不同的语义场
3. **统计**：分析各语义场的水平分布
4. **协同**：分析语义场之间的协同模式
5. **应用**：为命题设计、学业测量、教学诊断提供依据

## 5. 语义场协同模式

### 5.1 题点涉及的语义场数量

| 水平 | 平均涉及语义场数 | 单语义场 | 双语义场 | 三语义场 + |
|-----|---------------|---------|---------|----------|
| 水平 1 | 1.8 | 40% | 53% | 7% |
| 水平 2 | 2.1 | 27% | 53% | 20% |
| 水平 3 | 2.5 | 14% | 57% | 29% |
| 水平 4 | 2.9 | 6% | 44% | 50% |

**发现**：
- 水平越高，涉及的语义场越多
- 水平 4 半数题点涉及 3 个以上语义场
- 这说明高水平需要**跨语义场整合**

---

### 5.2 典型语义场协同模式

**模式 1：史料 + 解释（基础协同）**
```
题点 1.2：说明给定史料的类型和价值
  S2 史料（史料、类型、价值）+ S3 解释（说明）

题点 2.2：辨别史料类型并说明各自价值
  S2 史料（史料、类型、价值）+ S3 解释（辨别、说明）
```

**模式 2：时空 + 史料 + 解释（整合协同）**
```
题点 2.1：综合判断多则史料所反映史事的时空及特征
  S1 时空（时空）+ S2 史料（多则史料）+ S3 解释（判断、特征）
```

**模式 3：理论 + 解释 + 价值（高阶协同）**
```
题点 3.8：运用唯物史观说明、论述历史发展变化和社会形态演变的基本规律
  S4 理论（唯物史观）+ S3 解释（说明、论述、历史发展变化）+ S1 时空（社会形态演变）

题点 4.14：体现四个自信
  S5 价值（自信）+ S4 理论（社会主义）
```

---

### 5.3 语义场协同频率统计

- 时空 + 史料 + 解释是整合协同模式（水平 2-3）

## 6. 核心发现

### 发现 1：价值语义场是最大语义场

```
S5 价值：27 个名词（占总名词数 33%）
S3 解释：23 个名词（占 28%）
S2 史料：14 个名词（占 17%）
S1 时空：10 个名词（占 12%）
S4 理论：8 个名词（占 10%）
```

**解读**：
- 学业质量不仅是"能力标准"，更是"价值标准"
- 价值引领贯穿 4 个水平（从"举例认同"到"铸牢意识"）

---

### 发现 2：语义场数量是水平区分的指标

```
水平 1：平均 1.8 个语义场
水平 2：平均 2.1 个语义场
水平 3：平均 2.5 个语义场
水平 4：平均 2.9 个语义场
```

**解读**：
- 水平差异不仅是"能力高低"，更是"概念网络复杂度"
- 高水平需要跨语义场整合

---

### 发现 3：语义场协同模式揭示知识调用

```
低水平：单语义场或双语义场协同
  → S2+S3（史料 + 解释）

中水平：三语义场协同
  → S1+S2+S3（时空 + 史料 + 解释）

高水平：四语义场或五语义场协同
  → S1+S2+S3+S4+S5（全语义场整合）
```

**解读**：
- 学业质量是"概念网络的激活与整合"
- 高水平题点需要同时调用多个语义场

---

### 发现 4：理论语义场在水平 4 密集

```
S4 理论名词的水平分布：
  水平 1:3 个（唯物史观、基本观点、方法）
  水平 2:2 个（主要内容、科学性）
  水平 3:2 个（社会形态演变、基本规律）
  水平 4:4 个（历史依据、社会主义核心价值观、等）
```

**解读**：
- 水平 4 不仅是"能力高峰"，也是"理论高峰"
- 理论框架的自觉运用是水平 4 的特征

---

### 发现 5：价值语义场的"内化进阶"

```
水平 1：认同对象（家乡、民族、国家）
  → 具体对象举例

水平 2：认同对象 + 价值状态（认同、尊重）
  → 表达态度

水平 3：认同对象 + 价值状态 + 价值目标（人类命运共同体）
  → 具有意识

水平 4：认同对象 + 价值状态 + 价值目标 + 认同属性（内涵、自信）
  → 铸牢/树立意识
```

**解读**：
- 价值内化是从"具体"到"抽象"到"自觉"的进阶
- 水平 4 是价值内化的"质变点"
