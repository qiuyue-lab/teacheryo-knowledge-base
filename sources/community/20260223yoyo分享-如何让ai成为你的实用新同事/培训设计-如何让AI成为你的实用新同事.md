# 培训设计：如何让AI成为你的实用新同事

> 定位：道的层面的培训，不讲具体操作步骤，讲理念、概念和方向。
> 与书的关系：书的前置培训，帮老师建立认知框架，书展开细节。
> 受众：社群老师，不论AI使用程度，都能听懂。

---

## 整体逻辑

四个模块：**愿景 → 案例 → 概念 → 实践**

前两个模块打开认知（"原来可以这样想"），第三个模块建立框架（"原来有这几个关键概念"），第四个模块回到自己（"那我可以从哪里开始"）。

---

## 模块一：愿景 — 如果AI是你的新同事

**核心问题**：你现在跟AI是什么关系？

大多数老师跟AI的关系是"我问它答"——本质上是把AI当搜索引擎的升级版。但如果你把AI想象成一个新来的同事呢？同事不是你按一个按钮就给你结果的机器。同事有自己的专业背景、有判断力、有风格偏好，你跟同事合作的方式是对话、讨论、协商，而不是下指令。

这个认知切换是整场培训的起点：**从"使用AI"到"与AI协作"**。

这个切换为什么重要？因为它决定了你后面所有的用法。如果你把AI当工具，你会去找"最好用的工具"、学"最有效的指令"；如果你把AI当同事，你会去想"我需要什么样的同事"、"我怎么跟它配合"、"它擅长什么我擅长什么"。后者才是真正能深入下去的思路。

**这个模块要达到的效果**：老师们开始用"同事"的视角去重新看待AI。

---

## 模块二：案例 — 看看你的同行已经在做什么

**核心问题**：别人是怎么跟AI"合作"的？

展示社群老师在不同维度上的真实探索，不是为了让大家觉得"我也要这样做"，而是让大家看到可能性的宽度。

几个方向的案例：

- **学科深度方向**：炎鑫老师把AI用在命题分析上，拆解命题规则、标注能力点，让普通学校的学生理解命题人的逻辑。这不是"让AI出题"，是让AI帮你做专业分析。
- **全栈开发方向**：正己老师作为语文老师，用AI编程工具独立开发网站和小程序。证明了门槛的消失——有想法就能做出来。
- **极简工作流方向**：少川老师作为新手妈妈，用最少的工具搭出一套随时随地能用的AI备课系统。核心是"把自己想清楚"，而不是学更多技术。
- **系统搭建方向**：止水老师在做教师知识库的基础设施，让教师的数字化工作环境变得可管理、可复用。
- **一对一教学方向**：有老师在探索用AI做个性化的学生辅导和诊断。

这些案例的共同点是什么？每个老师切入的角度完全不同，但他们都不是在"用AI完成一个任务"，而是在**让AI进入自己的工作流**。差别只是进入的位置不同。

**这个模块要达到的效果**：老师们看到"原来AI能做的事情比我想的多得多"，同时意识到"每个人的切入点可以完全不同"。

## 模块三：概念 — 理解三个关键概念

从案例中提炼出三个需要理解的概念。这不是技术课，但这几个概念搞清楚了，后面自己探索的时候就不会走偏。

### 概念一：Skill和角色 — 两种不同的协作方式

**Skill**是一个定义好的能力模块。你给它一个输入，它按照设定好的流程执行，返回一个结果。比如"帮我把这段文字改成适合初中生的难度"——这是一个Skill，它做的事情是明确的、边界清晰的。

**角色**是一个有身份的协作者。它不只有能力，还有认知框架、专业偏好、判断标准。同样是帮你备课，一个Skill会按你说的做；一个角色会先理解你的教学理念，然后基于它自己的专业判断给你建议——它会追问、会质疑、会提供你没想到的角度。

这两者不是对立的。Skill可以是角色的一部分能力——就像一个同事既有自己的专业判断力，也会用Excel做表格一样。关键是理解它们各自是什么，这样你在不同场景下才知道自己需要的到底是哪种协作方式。

### 概念二：你的AI同事可以是谁

理解了Skill和角色的区别之后，接下来的问题是：那我的AI"同事"具体可以是谁？

答案是：取决于你需要什么。

**第一层：可能性是完全开放的**

社群里的老师们其实已经在给自己的AI同事"安排岗位"了，而且每个人安排的岗位完全不同。把目前已经出现的和可以想象到的可能性铺开来看：

| AI同事 | 它帮你做什么 |
|--------|------------|
| 命题分析专家 | 拆解命题规则、标注能力点、分析考试趋势（炎鑫老师在用） |
| 备课搭档 | 了解你的教学理念和好课标准，随时帮你出方案、讨论设计（少川老师在用） |
| 全栈工程师 | 帮你把想法变成网站、小程序、数据库（正己老师在用） |
| 知识管理架构师 | 搭建可管理、可检索、可复用的数字化工作环境（止水老师在用） |
| 学情诊断师 | 分析学生的认知卡点，找到每个学生到底卡在哪里 |
| 一对一辅导教练 | 针对单个学生的情况做个性化教学 |
| 教材分析师 | 深度解读教材意图、课标要求，帮你抓住一节课的核心 |
| 作业分析师 | 批量分析学生作业，发现共性错误和个别问题 |
| 家校沟通顾问 | 帮你拟家长信、沟通方案，处理敏感话题的措辞 |
| 跨学科连接者 | 在你的学科内容中发现与其他学科的连接点，设计融合课 |
| 班级数据分析师 | 分析班级整体学情数据，发现趋势和异常 |
| 评课专家 | 帮你复盘一节课，从不同维度给出分析和改进建议 |
| …… | 你需要什么样的同事，就可以有什么样的同事 |

这张表永远列不完，因为每个老师的需求、学科、学段、教学风格都不一样。关键是你想清楚"我需要一个什么样的人来帮我"，这个"谁"就自然浮现了。

**第二层：三个值得特别关注的角色方向**

在这么多可能性里面，有三个方向值得特别说一下，因为它们对应的不是某个具体任务，而是教师专业成长的三个根本维度——过去、当下和未来：

| 角色 | 解决什么问题 | 时间朝向 |
|------|------------|---------|
| **Skill梳理师** | 你教了很多年，有很多好的做法，但你自己说不出来为什么好。这个角色帮你把无意识的好变成有意识的方法论——**认识自己** | 回溯过去 |
| **AI教研员** | 你一个人备课没人讨论，质量全靠个人状态。这个角色不是帮你写教案，而是帮你思考教学设计、分析重难点、提供多种策略让你选——**设计当下** | 聚焦当前 |
| **创意激发师** | 同样的内容教了五年十年，学生觉得无聊你也觉得无聊。这个角色专门帮你打破惯性，从跨界的角度给你"哎？还可以这样？"的灵感——**突破未来** | 面向创新 |

为什么要单独提这三个？因为上面列的那些AI同事——命题专家、备课搭档、作业分析师——大多是在帮你完成某个具体任务。而这三个角色指向的是一个更底层的问题：你作为老师，怎么持续成长？先看见自己已经有什么（过去），再把当下的课设计得更好（现在），再不断突破自己的边界（未来）。这条线不是替代上面那些具体的AI同事，而是给你一个思考自己需求的框架。

### 概念三：对话即协作

跟AI的协作本质上是通过对话完成的。对话质量决定了协作质量。这跟你和真人同事合作是一样的——你跟同事说"帮我弄个东西"和"我这节课想解决学生在分数概念上的一个典型误区，学生总是把分数当成两个独立的数，你觉得用什么方式能让他们真正理解部分与整体的关系"，得到的结果完全不一样。

关键不是学话术，而是想清楚自己要什么、把背景说清楚、把标准讲明白。这件事跟技术无关，跟你的专业思考有关。

**这个模块要达到的效果**：老师们理解了Skill和角色的区别，看到AI同事可以有很多种"岗位"，并且意识到"会对话"才是核心能力。

## 模块四：实践 — 找到你的切入点

**核心问题**：我从哪里开始？

### 从你的真实需求出发

不需要一步到位把所有东西都用上。回到你自己：你现在备课最大的痛点是什么？是没时间深入研究教材？是找不到好的教学创意？是不知道学生到底卡在哪里？是做了很多年但说不出自己的方法论？

每个痛点对应不同的切入方式：
- 如果你最缺的是"有人讨论" → 从AI教研员开始
- 如果你觉得自己有好方法但没整理过 → 从Skill梳理师开始
- 如果你觉得自己的课需要新鲜感 → 从创意激发师开始

### 工具观：所有工具都是为了干活服务的

市面上的AI工具很多——DeepSeek、Kimi、豆包、ChatGPT，还有各种平台和插件。不要被工具绑架。工具会不断更新换代，但你的需求是稳定的。

正确的思路是：先想清楚"我要做什么事"，再去找"什么工具能帮我做这件事"。不是反过来——先学了一个工具，再想"这个工具能干什么"。

社群里的案例也印证了这一点：少川老师用的是最简单的工具组合，照样搭出了她的系统；正己老师用的是最硬核的开发工具，做的是完全不同的事。工具没有高下之分，只有合不合适。

### 可以推荐的起步路径

对于大多数老师来说，最低门槛的开始方式：

1. 打开任何一个你能用的AI对话工具
2. 把你正在备的一节课的内容和困惑告诉它
3. 像跟同事聊天一样，讨论这节课可以怎么教

就这么简单。不需要学任何Prompt技巧，不需要注册任何新平台。先有一次真实的"协作体验"，然后你自然会知道下一步想往哪个方向走。

**这个模块要达到的效果**：老师们知道自己可以从哪里开始，不再觉得"AI这件事太复杂我不知道怎么入手"。

| 概念 | 30% | 讲清楚三个关键概念 |
| 实践 | 30% | 回到每个人自己，找到切入点 |
