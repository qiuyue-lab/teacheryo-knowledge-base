# 文章解析模板

QClaw 拿到每篇公众号文章后，按以下格式输出 Markdown 文件：

---

```markdown
---
title: 文章标题
date: 发布日期
source: 公众号链接
data_performance: 阅读量 / 点赞 / 在看 / 转发（如果有）
tags: [AI教育, 教学理念, ...]
---

## 一句话摘要
用一句话概括这篇文章的核心主张。

## 核心教学理念（如有）
提炼出文章中体现的教学理念，用作者的原话 + 归纳。

## 关键观点与金句
- 观点1："原文金句" —— 归纳
- 观点2：...

## 数据与案例（如有）
记录文章中提到的具体数据、案例、实验结果。

## 写作偏好观察（如有）
- 文章类型：问题牵引型 / 框架提炼型 / 案例反思型 / 反常识观点型 / 其他
- 标题钩子：这个标题靠什么吸引读者？
- 开头方式：具体场景 / 真实对话 / 反常识判断 / 最近观察 / 其他
- 结构节奏：文章如何从问题推进到观点或框架？
- 典型语气：哪些句子体现了 YoYo 的表达习惯？
- 可复用写法：以后写公众号时可以复用什么？

## 与知识库已有内容的关联
这篇文章和已有的哪些理念/观点有关？是补充、深化还是新方向？
```
