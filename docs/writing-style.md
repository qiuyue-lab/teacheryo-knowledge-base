# 公众号写作偏好

> 用于指导 AI 生成、改写或续写 YoYo 的公众号文章。它不是选题库，而是判断一篇文章“像不像 YoYo 写的”的风格标准。

## 核心写作观

YoYo 的公众号写作不是单纯输出信息，而是在创造一个认知发生的场。

好的文章不只是“把观点讲清楚”，而是让读者在阅读过程中经历一次小的认知移动：先被一个真实问题拉进来，再看见背后的结构，最后带走一个能继续使用的判断或框架。

## 文章的基本气质

### 1. 直接，但不装作绝对正确

文章可以有鲜明判断，甚至可以挑战主流说法，但要保留开放性。

- 可以说：“我的判断是……”
- 可以说：“我越来越觉得……”
- 可以说：“这不一定对，但至少我现在是这样看的。”
- 避免说：“毫无疑问”“必然如此”“唯一正确答案”

YoYo 的表达不是温和中立，而是“直接表达 + 承认不确定”。

### 2. 从具体场景进入，不从抽象概念进入

文章开头最好有一个真实问题、一个具体画面、一次对话、一个教学场景或一个最近的观察。

不推荐一上来定义概念，比如“AI 时代教育正在发生深刻变革”。这种开头太像报告。

更像 YoYo 的写法是：

- “最近我和一个老师聊到一个问题……”
- “我发现很多老师用 AI 的第一步就错了。”
- “这几天我一直在想一件事……”
- “有个现象挺有意思。”

### 3. 观点要有结构，但不要像论文

YoYo 的文章经常会提出框架，比如三层、三阶段、四原则、五个阶段。但这些框架不是为了显得专业，而是为了帮读者抓住复杂问题。

结构要服务于理解，不要服务于炫技。

好的结构通常长这样：

- 先指出一个常见误区
- 再解释这个误区为什么会出现
- 然后提出一个新的看法或框架
- 最后说明它能怎么用

### 4. 口语化，但不是随便

语言要像一个人在认真说话，而不是像机构公号、产品白皮书或教育论文。

可以有这些表达：

- “说白了”
- “这件事最麻烦的地方在于”
- “我不太喜欢这个说法”
- “问题不在这里”
- “真正难的是”
- “这就很有意思了”

少用这些表达：

- “赋能”
- “闭环”
- “生态”
- “抓手”
- “底座”
- “矩阵”
- “打造”
- “全面提升”

除非是在批判或引用，否则尽量避免典型 AI 味和机构味。

## 常用文章结构

### 1. 问题牵引型

适合写教育观察、AI 教育判断、教师困境。

结构：

1. 从一个具体问题或现象开头
2. 说明这个问题为什么不是表面看起来那样
3. 拆出更深层的结构
4. 给出新的判断
5. 回到教师、学生或家长能做什么

### 2. 框架提炼型

适合写方法论、课程设计、AI 使用路径。

结构：

1. 说明自己为什么开始思考这个问题
2. 指出原来的做法哪里不够
3. 提出一个简洁框架
4. 逐层解释每一部分
5. 用具体场景说明怎么使用

### 3. 案例反思型

适合写社群案例、老师实践、产品观察。

结构：

1. 先讲一个具体案例
2. 说明它真正打动人的点
3. 从案例里抽象出一个更大的问题
4. 回到 AI 时代教育的变化
5. 提炼出可迁移的启发

### 4. 反常识观点型

适合写传播力较强的文章。

结构：

1. 开头抛出一个挑战常识的判断
2. 解释为什么常见理解有问题
3. 给出自己的重新定义
4. 用案例或推理支撑
5. 结尾留下一个更大的问题

## 标题偏好

YoYo 的标题通常要有一个清晰的认知钩子，而不是泛泛描述。

常见标题类型：

- 直接判断型：`AI替代产出，但替代不了成长`
- 问题型：`AI时代，作业应该怎么留？`
- 转折型：`你需要的不是AI，是私人AI助理`
- 方法论型：`我的课程设计方法论`
- 场景型：`当我开始使用Gemini进行备课`

标题不要太像课程广告，也不要太像机构报告。标题要让人感觉“这里有一个我没想清楚但很重要的问题”。

## 开头偏好

开头要尽快把读者带进问题，而不是铺背景。

推荐：

- 真实观察
- 最近一次对话
- 一个具体困惑
- 一个反常识判断
- 一个“我最近越来越觉得”的思考入口

不推荐：

- 宏大时代背景
- 定义式开头
- 过度煽情
- “随着 AI 技术的发展……”

## 结尾偏好

结尾不一定要给标准答案。很多时候，YoYo 的文章更适合停在一个开放但有力量的判断上。

好的结尾通常有三种：

- 回到人：老师、学生、家长到底发生了什么变化
- 回到选择：在这个现实里我们还能怎么做
- 回到问题：这个问题我还没想完，但它值得继续想

避免结尾突然变成口号、鸡汤或课程转化文案。

## 修改文章时的判断标准

当 AI 帮 YoYo 写公众号文章时，要优先检查这些问题：

1. 这篇文章有没有一个清晰的核心判断？
2. 它是不是从具体场景进入，而不是从抽象概念进入？
3. 它有没有制造认知冲击，而不是只是在科普？
4. 它有没有保留 YoYo 的真诚和不确定性？
5. 它的框架是不是为了帮助理解，而不是为了显得高级？
6. 它有没有过多机构味、AI 味、营销味？
7. 读者看完后能不能带走一个新的看法或一个可使用的框架？
